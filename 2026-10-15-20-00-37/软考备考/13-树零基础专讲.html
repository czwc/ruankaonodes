第0课 · 树是什么（先建立画面，再看术语）

树就是"往下分叉的组织架构图"。想象一家公司：老板在最上面，手下带几个总监，总监再带员工——把它倒过来画（老板在上），就是一棵"树"。 
        老板(CEO)          ← 【根】最顶上那个，没有上级
        /        \
     总监A        总监B      ← 中间层，有上也有下
     /   \          \
  员工a   员工b      员工c    ← 【叶子】最底下，没有下级
考试黑话对照表（出现这些词就想起这张图）：
· 根 = 老板（唯一，最顶上）
· 叶子（叶节点） = 没有下级的员工（最末端）
· 度 = 一个人的直接下级个数（总监A 管 2 人 → 度为 2；员工谁都不管 → 度为 0）
· 深度/层数 = 老板是第 1 层，总监第 2 层，员工第 3 层（从 1 数起）
· 子树 = 拎出任何一个"部门"单独看，它自己也是一棵小树
一句话记住：树 = 一对多的分叉关系，有且只有一个根，没有环（上级不能反过来当你的下级）。

第1课 · 二叉树（考试 95% 只考这种）

二叉树 = 每个人最多带俩下级（左下级叫左孩子，右下级叫右孩子）。就这么简单。

满二叉树 vs 完全二叉树（每年爱考"谁是谁"）

  满（每层都塞满）：        完全（只准缺右边，不准跳着缺）：
        1                       1
       / \                     / \
      2   3                   2   3
     / \ / \                 / \ /
    4  5 6  7               4   5
白话区分：
· 满二叉树 = 每一层都挤得满满当当，像满员电影院（上图的 1~7 一层不多一层不少）。
· 完全二叉树 = 按"从上到下、从左到右"的顺序入座，允许最后一排没坐满，但空座只能在右边（上图右：4 和 5 坐了，6、7 位置空着——合法；要是只有 4 和 6 到场、5 空着，就不算完全二叉树）。
· 满一定是完全，完全不一定是满。
附带一个送分结论：完全二叉树可以塞进数组里按 1,2,3… 编号存放，此时编号 i 的人：左孩子 = 2i，右孩子 = 2i+1，父 = i÷2 取整。例：3 号的左孩子是 6 号。考法："编号为 i 的节点，其右孩子的编号是？" → 2i+1。

第2课 · 三条必背性质（考试直接套数字）

性质① 第 i 层最多 2^(i−1) 个节点。 白话：老板独占第 1 层（2⁰=1 人）；每个人都能带俩下级，所以每往下一层人数翻倍——第 2 层 2 人、第 3 层 4 人、第 4 层 8 人。第 i 层 = 2 的 (i−1) 次方。
性质② 深度为 k 的二叉树，最多 2^k − 1 个节点。 白话：把每层都塞满（就是满二叉树），全树总人数 = 1+2+4+…+2^(k−1) = 2^k − 1。例：深度 4 → 1+2+4+8 = 15。
性质③ 叶子数 = 度为 2 的节点数 + 1（n0 = n2 + 1）。 白话：每多一个"带俩下级的"（度为 2），就必多一个"光杆员工"（叶子）。注意度为 1 的节点不参与这个等式——它只带一个下级，不影响平衡。例：一棵树有 7 个度为 2 的节点、3 个度为 1 的节点 → 叶子 = 7+1 = 8（3 那个数字是烟雾弹）。
延伸一条（完全二叉树专用）：完全二叉树共 n 个节点 → 叶子数 = n÷2 向上取整。例：n=100 → 叶子 50 个。

现场练 2 道（点开对答案）

练1 深度为 5 的二叉树最多有多少个节点？
套性质②：2⁵−1 = 31（1+2+4+8+16）。别忘减 1，这是最常见的失误。
练2 一棵二叉树有 12 个度为 2 的节点、5 个度为 1 的节点，叶子几个？
套性质③：n0 = n2 + 1 = 12+1 = 13。"5 个度为 1"完全不用管，出题人故意放的干扰。

第3课 · 三种遍历（★每年必考，学会这课就拿稳 1~2 分）

遍历 = 把所有节点不重不漏地"点名"一遍。三种遍历的区别只有一句话：前/中/后，说的都是"根"被点名的时机——根在前=前序，根在中间=中序，根在最后=后序。左右顺序永远不变（永远先左后右）。

用下面这棵树练（建议拿草稿纸照着画一遍，比看十遍有用）：

        A
       / \
      B   C
     / \    \
    D   E    F
前序（根→左→右）：先点根 A；再看 A 的左子树：根 B，B 的左 D，B 的右 E → D、E；最后 A 的右子树：根 C，C 没左孩子，C 的右 F。
答案：A B D E C F
中序（左→根→右）：记住一个直觉——把树垂直压扁投影到地上，从左往右读。A 的左半边先：B 的左边 D 先落地，然后 B，然后 E；然后 A 自己；然后右半边：C 的左边是空的，所以 C 先，再 F。
答案：D B E A C F
后序（左→右→根）：根 A 憋到最后。左子树：D、E 都出来了才轮到 B；右子树：F 出来才轮到 C；最后 A。
答案：D E B F C A
三个秒杀结论（爱直接考）：① 前序第一个一定是根；② 中序里根把序列切成左右两半（左边的都是左子树，右边的都是右子树）；③ 后序最后一个一定是根。第4课还原整棵树全靠①②。

自己走一遍（必须动手）

练3 上面那棵树 A(B(D,E),C(F))，合上答案自己默走一遍前序，卡住了就回口诀"根→左→右"
A → 左子树(B,D,E)：B 先，D、E 后 → 右子树(C,F)：C 先，F 后。前序 = A B D E C F。
练4 换棵树：根 R，左孩子 X（X 的左孩子 Y），右孩子 Z。求中序
左半边先：Y（X 的左边）落地，然后 X；然后 R 自己；最后右边的 Z。中序 = Y X R Z。自检：R 把序列分成左 {Y,X}、右 {Z}，跟树的分叉一致，答案靠谱。

第4课 · 两个序列还原整棵树（★下午/上午都考，有固定三步）

考法：给你"前序 + 中序"，让你求"后序"。不需要真的画完整棵树，用三步递推就能写出来：
第①步：前序的第一个 = 根。
第②步：拿根去中序里找，把中序切成左半、右半（左半=左子树成员，右半=右子树成员）。
第③步：对左右两半各重复①②（每半的前序=从原前序里按顺序挑出这半的字母），直到切完。最后按"左→右→根"拼起来就是后序。

完整例题：前序 ABDECF，中序 DBEAFC，求后序

第①轮：前序 [A]BDECF → 根 = A
        中序  D B E | A | F C → 左半 {D,B,E}，右半 {F,C}

第②轮（左半）：前序 [B]DE → 根 = B
        中序  D | B | E → 左 {D}，右 {E}   （D、E 都是叶子，切完）

第②轮（右半）：前序 [C]F → 根 = C
        中序  F | C → 左 {F}，右 空       （F 是 C 的左叶子）

拼后序（左→右→根）：
  左子树的后序 = D E B
  右子树的后序 = F C
  最后放根 A
  → 后序 = D E B F C A
易错点：①中序切根时，根自己要挖掉（不留给左右）；②拼后序时根放最后不是最前；③左右两半在前序里的顺序 = 原前序里的相对顺序，照抄别打乱。
练5 前序 ABDEC，中序 DBEAC，求后序
根 A；中序切出左 {D,B,E}、右 {C}。左半：前序 BDE → 根 B，中序 DBE → 左 D 右 E。右半就一个 C（叶子）。拼：D E B + C + A = D E B C A。

第5课 · 哈夫曼树（★必考手算，规则只有一条）

哈夫曼解决什么问题：把"使用频率不同的东西"编码，让常用的最短、总代价最小。像食堂打饭——天天来的常客给快捷通道。考试不考原理，只考手算建树 + 算 WPL。
建树规则（唯一一条）：把所有数字放池子里，每次挑最小的两个拿出来合并（和 = 两数相加），把和放回池子，重复，直到池子只剩一个数。

完整例题：{1, 2, 3, 4, 5} 建哈夫曼树

池 {1,2,3,4,5}
  ① 挑最小俩：1+2=3  → 池 {3,3,4,5}   （新合出的 3 放回去）
  ② 再挑最小俩：3+3=6 → 池 {4,5,6}    （"原始3"和"新3"合并）
  ③ 再挑：4+5=9       → 池 {6,9}      （原始的 4 和 5 合并）
  ④ 最后：6+9=15      → 池 {15}，完毕。15 = 根

最终树形（图中 (3) 是第①步合出来的"新3"，别和原始 3 搞混）：
                15
              /    \
             6      9
            / \    / \
           3  (3) 4   5
              / \
             1   2

关键认领：
  · 6  = 原始3 + 新3   合出来的（第②步）
  · 9  = 原始4 + 原始5 合出来的（第③步）
  · 15 = 6 + 9         合出来的（第④步，当根）
  · 原始数字 1,2,3,4,5 全都是叶子
算 WPL（带权路径长度）= 每个原始数字 × 它离根隔几条线，全部加起来：
拿上图数线：3、4、5 都只隔 2 条线（15→6→3；15→9→4；15→9→5）；1、2 隔 3 条线（15→6→(3)→1 或 2）。
WPL = 3×2 + 4×2 + 5×2 + 1×3 + 2×3 = 6+8+10+3+6 = 33
偷懒验算（强烈推荐）：WPL = 每次"合并出来的和"加一遍。例题里合并出的和是 3、6、9、15 → 3+6+9+15 = 33 ✓。跟逐步乘层数结果必然一样，考场用它验算最快。
哈夫曼三条必背结论：①哈夫曼树没有度为 1 的节点（每个合出来的节点必带俩孩子）；②n 个叶子 → 全树共 2n−1 个节点（例：5 个叶子 → 9 个节点，数上图：1,2,3,4,5 + 3,6,9,15 = 9 ✓）；③哈夫曼编码是前缀码——任何编码都不是另一个的开头，所以连在一起读不会歧义（左=0 右=1，数字越常用编码越短）。
易错点：①每次挑的"最小俩"要把新合出来的和也算进池子一起比大小；②WPL 数层数时根是第 1 层（有的教材根算第 0 层，软考按"边数"算路径长——数字离根隔几条线就乘几，两种说法结果一致，按"隔几条线"理解最保险）。
练6 {2, 3, 5, 7} 建哈夫曼树，WPL = ？
2+3=5 → 池{5,5,7}；5+5=10 → 池{7,10}；7+10=17。验算法：WPL = 5+10+17 = 32。逐步验：7 在第 1 层（×1=7）、原始 5 在第 2 层（×2=10）、2 和 3 在第 3 层（3×2+3×3=6+9=15）→ 7+10+15 = 32 ✓。

第6课 · 二叉排序树 BST（左小右大，送分 1 分）

规则就一句：左子树所有值 < 根 < 右子树所有值。像查字典——比当前页的词小就往左翻，大就往右翻，每次排除一半。

插入演示：依次插入 45, 24, 53, 12, 37

45 当根
  24 比 45 小 → 去左，45 左边空 → 落座
  53 比 45 大 → 去右 → 落座
  12 比 45 小去左 → 比 24 小再左 → 落座
  37 比 45 小去左 → 比 24 大去右 → 落座

        45
       /  \
     24    53
    /  \
  12    37
考法就两种：
① 查找某数比较几次？ = 沿途比过的节点个数。上树找 37：45→24→37，3 次；找 60：45→53→左边空 → 3 次后宣告"没有"。
② 中序遍历 BST 得到什么？ → 从小到大的有序序列（12 24 37 45 53，考试爱考这个结论）。
练7 依次插入 50, 30, 70, 20, 40, 60，问 40 落在哪？找 60 比几次？
50 根；30 去左；70 去右；20 → 30 左；40 → 30 右。40 是 30 的右孩子。找 60：50→70→60？60 比 70 小去左 → 落在 70 左孩子位置；若查找 60：比较 50、70、60 = 3 次。

第6.5课 · 平衡二叉树 AVL 与 树↔二叉树（概念送分题）

平衡二叉树（AVL）：任意节点的左右子树高度差 ≤ 1。平衡因子 = 左子树高 − 右子树高，取值只有 -1/0/1。考试只考：①给一棵树算几个节点的平衡因子、判断是否平衡；②插入导致失衡要"旋转"恢复（考概念不考画图）。
树 / 森林转二叉树（孩子兄弟法）：节点的第一个孩子 → 左孩子；相邻兄弟 → 右孩子。口诀"长子作左、兄弟作右"。树转出来的二叉树根没有右子树——真题给树/森林选二叉树形态，按这两句画即可。

毕业自测 8 题（全对才算过关，错的重回对应课）

① 深度为 6 的二叉树最多多少节点？（第2课）
2⁶−1 = 63。
② 度为 2 的节点有 10 个，叶子几个？度为 1 的有 8 个，要管吗？（第2课）
n0 = n2+1 = 11；度 1 的 8 个不管，干扰项。
③ 前序 ABDEC、中序 DBEAC，后序 = ？（第4课）
根 A → 左{D,B,E} 右{C}；左半根 B，左 D 右 E。后序 = D E B C A。
④ {2,3,5,7} 建哈夫曼树，WPL = ？（第5课）
合并和：5、10、17 → WPL = 32。
⑤ n 个叶子的哈夫曼树共几个节点？有没有度为 1 的节点？（第5课）
2n−1 个；没有度为 1 的节点。
⑥ 中序遍历二叉排序树，得到什么？（第6课）
从小到大排好序的序列。
⑦ 一棵树最后一层只空了最右边两个位置，它是满二叉树还是完全二叉树？（第1课）
完全二叉树（不是满——满要求每层全塞满；只缺右边 = 完全）。
⑧ 数组存放的完全二叉树中，编号 i 的节点，右孩子编号 = ？（第1课）
2i+1（左孩子 2i，父 i÷2 取整）。
