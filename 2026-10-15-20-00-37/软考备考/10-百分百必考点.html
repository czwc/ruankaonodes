上午 · 铁打必考（14 张，近 10 年年年出）

★必开发模型选型1~2 分

考给一段项目描述，问"适合采用什么模型"。

解见字眼对号：风险分析→螺旋；需求不明先做样→原型；分批交付核心先行→增量；文档驱动阶段评审→瀑布；每日站会→敏捷。

坑把增量当原型——增量是"分批上线可用版本"，原型是"先做个样子给用户确认需求"。

★必白盒覆盖 + McCabe1~2 分

考①问覆盖强度排序；②给程序图求环形复杂度。

解由弱到强：语句＜判定＜条件＜判定/条件＜条件组合＜路径；V(G) = 边 − 点 + 2。例：10 条边 8 个节点 → 10−8+2 = 4，用例至少 4 个。

坑别把"语句覆盖"当最强；McCabe 公式别写成"点−边"。

★必耦合内聚排序1~2 分

考描述模块关系问"属于什么耦合/内聚"或"最差的是"。

解耦合数标控外公内（直接改别人内部数据=内容耦合最差）；内聚功顺通过时逻偶（凑一起没联系=偶然最差）。

坑顺序内聚 vs 通信内聚：顺序是"上一步输出=下一步输入"，通信是"围绕同一数据集各自干活"。

★必设计模式固定 2~3 分

考给场景描述选模式（下午还考代码填空）。

解唯一实例→单例；状态变通知所有依赖者→观察者；动态加职责不加子类→装饰器；算法可替换→策略；行为随内部状态变→状态；创建延迟到子类→工厂方法。

坑状态 vs 策略：状态是"对象自己切换行为类"，策略是"外部换算法"，考题爱混着出。

★必流水线1~2 分

考给各段耗时和指令条数，求总时间/加速比/吞吐率。

解例：四段 1/2/3/4ns 跑 100 条 → 周期=最长段 4ns；总时间 = (1+2+3+4) + 99×4 = 406ns；加速比 = 1000÷406 ≈ 2.46。

坑第一条指令 = 各段之和（10ns），别用周期代替；吞吐率 = n÷总时间。

★必Cache 平均访问时间1 分

考给命中率与两级存取时间求平均时间。

解顺序式：0.9×40 + 0.1×200 = 56ns；同时访问式：0.9×40 + 0.1×(40+200) = 60ns。

坑题干出现"同时访问"四个字，第二项必须把 Cache 时间也算进去。

★必可靠性1 分

考给串并联混联图求系统可靠度。

解串联相乘、并联 1−∏(1−R)。例：两个子系统串联、各由 2 个 0.9 并联 → 每个 = 1−0.1² = 0.99 → 系统 = 0.99² = 0.9801。

坑口诀"先小后大"：先把每个子系统算成一个数，再串联。

★必页式地址转换1~2 分

考给页大小、逻辑地址、页帧映射，求物理地址。

解例：页 1KB、地址 2500、帧号 4 → 页号 = 2500÷1024 = 2（商），偏移 = 452（余）→ 物理 = 4×1024+452 = 4548。

坑帧号查题干映射表，别拿页号直接当帧号；4KB 页就用 4096 除。

★必排序1~2 分

考①问稳定性/复杂度；②给序列问"第一趟后"的样子。

解45,23,12,9 第一趟：插入→23,45,12,9（只前 2 有序）；冒泡→23,12,9,45（最大沉底）；选择→9,23,12,45（最小换到首位）；快排（枢轴45）→45 落最终位。

坑不稳定口诀"快些选堆"；希尔一趟是"按增量分组各排"，与其他不同。

★必二叉树1~2 分

考①给 n0 求 n2；②给前序+中序求后序。

解n0 = n2+1（5 叶子 → n2=4）。重建：前序 ABDECF + 中序 DBEAFC → 根 A 切两半 → 左 BDE 右 FC → 递归 → 后序 DEBFCA。

坑每一层都要"回前序找根、回中序切左右"；哈夫曼 2n−1 且无度 1 节点。

★必子网划分1 分

考给 IP/掩码求可用主机数或子网数。

解/27 → 主机位 5 → 可用 = 2⁵−2 = 30；比 /24 多 3 位网络号 → 子网数 = 2³ = 8。

坑必须减 2（网络地址+广播地址）；127.0.0.1 回环、169.254 自动专用。

★必TCP/UDP + 协议端口1~2 分

考给特征选协议、给应用配协议/端口。

解面向连接可靠三次握手 = TCP（网页/邮件/文件）；无连接快 = UDP（视频/语音/DNS）。端口：FTP21、SMTP25、DNS53、HTTP80、HTTPS443。

坑"实时视频流"选 UDP 不是 TCP；DHCP 是自动分 IP 不是 DNS。

★必PV 操作1~2 分

考给伪代码空格填 P/V，或问信号量初值。

解生产者：P(empty)→P(mutex)→放→V(mutex)→V(full)；消费者对称。初值：empty=n、full=0、mutex=1。

坑两个 P 顺序反了会死锁（拿互斥等资源）；mutex 的 P/V 必须成对夹住操作。

★必知识产权2~3 分

考给情境问"归谁/侵权吗/保护期多久"。

解委托开发无约定→受托方；职务开发→公司；著作权自动取得（登记不是前提）；发明 20、实用新型 10、外观 15（自申请日）；商标 10 可无限续展；著作权财产权 = 终生+50。

坑"登记证书"≠取得著作权；专利才需要"申请授予"。

上午 · 高频必出（8 张，近 5 年每年出）

★高频进程三态1 分

考画 6 条箭头问"哪条转换不存在"。

解就绪→运行（被调度）、运行→就绪（时间片到）、运行→阻塞（等资源）、阻塞→就绪（资源到位）；阻塞→运行不存在。

坑运行可以直接到阻塞（主动等 I/O），但阻塞必须先回就绪。

★高频范式判定1~2 分

考给关系模式和函数依赖，判最高范式。

解例 R(A,B,C,D)，A→B、B→C、A→D：A 只在左边→候选码；A→B→C 传递依赖 → 最高 2NF；分解 R1(A,B,D)+R2(B,C) 达 3NF。

坑单属性候选码自动满足 2NF（没有"部分"可谈）；传递链 A→B→C 才算。

★高频信息安全1~2 分

考给场景选技术/算法，或问"保证了什么"。

解防抵赖→数字签名（发送方私钥签）；防篡改→摘要；保密→公钥加密；HTTPS→混合（非对称传对称密钥）；IDS 报警、IPS 阻断。

坑签名不保密、加密不防抵赖——两个"保证"别混。

★高频新技术1~3 分

考名词场景对号入座。

解租硬件=IaaS、租环境=PaaS、用成品=SaaS；去中心化+智能合约=区块链；CI/CD=DevOps；就近处理=边缘计算；虚拟实时映射=数字孪生。

坑"租服务器自己装系统"是 IaaS 不是 PaaS；SaaS 是直接用在线软件。

★高频SQL 关键字1 分

考给需求问用哪个子句/授权语句。

解每组筛选（配聚合）→ HAVING；可转授 → WITH GRANT OPTION；虚表 → 视图；回收 → REVOKE。

坑WHERE 不能配聚合函数；执行顺序 WHERE→GROUP→HAVING→ORDER。

★高频校验码 + 海明1 分

考给数据位求海明校验位数，或问"谁能纠错"。

解2^k ≥ n+k+1：8 位数据 → 2⁴=16 ≥ 13 → k=4。奇偶/CRC 只能检错；海明能纠 1 位错。

坑CRC 是"模 2 除法"检错码，别和海明混淆。

★高频死锁1 分

考四条件辨析、银行家算法定位。

解四条件：互斥/请求保持/不剥夺/环路等待；银行家算法 = 避免死锁；破坏任一条件 = 预防。

坑"避免"和"预防"是两个层次——银行家是判断分配是否安全，不是提前破坏条件。

★高频专业英语固定 5 分

考一篇技术短文 5 个空四选一。

解先看选项词性（名词/动词/形容词），再回原文找同义复现与固定搭配；主题多为软件工程/开发方法。

坑别通读全文——5 空平均每题只读空格前后一句；高频词表见 09 Day3。

下午 · 必答套路（4 张，三大题送分部分）

★必试题一 数据流图15 分送分段

考补数据流/补实体/补加工名，或问父子图平衡。

解黑洞=只进不出、奇迹=只出不进，逐个加工查；实体顺着缺失数据流两端找"人/组织/外部系统"；命名=动词+名词。

坑父子平衡：0 层图有的输入输出，子图必须有——逐条对账别漏；答案全是找出来的，不是编的。

★必试题二 数据库设计15 分送分段

考补 E-R 联系及类型、转关系模式标主外键。

解两边各问一次定 1:n/m:n；m:n 独立建表（主键=两端主键组合，都是外键）；1:n 并入 n 端；"成绩/数量/金额"挂联系上。

坑1:n 别独立建表（那是 m:n 的待遇）；新需求题先判断"数据挂在谁身上"再决定加不加实体。

★必试题三 UML15 分送分段

考填类图箭头/补用例图，最后一问考设计模式。

解实线三角=泛化、虚线三角=实现、空心菱形=聚合、实心=组合；include 必选复用、extend 可选扩展；最后一问答题模板：模式名+场景理由+类名对应。

坑extend 箭头方向与 include 相反；聚合可分离、组合同生共死。

★必试题六 Java（选答）15 分

考给场景+类图+框架代码，填 3~5 个空。

解三步：读场景定模式 → 看空位类型（接口/成员/方法体）→ 套骨架（单例=私有静态+getInstance；观察者=notify/update；装饰器=持有同类型成员）。

坑先抄类图里已有的方法名再补逻辑；只主攻 Java，考场上直接选试题六放弃 C++。
