① 一眼认策略：四句话特征表 先背这张表

策略识别特征（题干/代码里找这些词）经典题目
分治"分成两半""分别求解""再合并"；代码有递归调用自己 + 合并归并排序、快速排序、二分查找、大整数乘法
贪心"每次选取当前最优""不回头"；通常是排序后一遍循环活动选择、部分背包、找零钱、哈夫曼编码
动态规划"最优解包含子问题最优解"；代码有二维表 dp[i][j] 或递推式0-1背包、最长公共子序列、最大子段和
回溯"试探""不满足则退回""剪枝"；代码是递归 + 撤销选择N 皇后、迷宫、子集/排列枚举
快速区分（考试最常混淆的两组）：
① 贪心 vs 动态规划：贪心只做选择不回头，快但可能不是全局最优；DP 枚举所有子问题保证最优，慢但一定对。题干说"求最优"且数据小 → DP；说"近似/快速"或明确"每步取最优" → 贪心。
② 分治 vs DP：分治的子问题互不重叠（二分）；DP 的子问题大量重叠（要填表避免重复算）。

② 分治法：拆 → 解 → 合 三步曲

// 例：归并排序 —— 把数组拆两半，各自排好，再合并
void mergeSort(int a[], int lo, int hi) {
    if (lo >= hi) return;          // ① 终止：只剩 0/1 个元素
    int mid = (lo + hi) / 2;        // ② 拆：从中点分成两半
    mergeSort(a, lo, mid);           // ③ 解：递归排左半
    mergeSort(a, mid+1, hi);         // ③ 解：递归排右半
    merge(a, lo, mid, hi);           // ④ 合：合并两个有序段（挖空高频处！）
}
考试填空点：递归区间边界（lo, mid / mid+1, hi）、merge 的合并条件。记住"左闭到 mid，右开从 mid+1"。

③ 贪心法：每步局部最优，绝不回头

// 例：活动选择 —— n 个活动按结束时间排序，能选就选
sort(act, act+n, cmp);              // 按结束时间从小到大排序（贪心的关键）
cnt = 1; last = act[0].end;
for (i = 1; i < n; i++)
    if (act[i].start >= last) {    // 与上一个已选活动不冲突
        cnt++; last = act[i].end;
    }
贪心反例（必懂，考过简答）：0-1 背包不能用贪心。物品 w=[10,20,30]，v=[60,100,120]，容量 50：
按性价比贪心选 10、20 → 价值 160；最优解选 20、30 → 价值 220。贪心装不下第三件也不回头，就输了。
（部分背包允许切分物品时才能用贪心，此时性价比排序是正确的。）

④ 动态规划：下午题最爱的策略 重点·手把手填表

三要素（答题要用术语）：① 最优子结构（大问题最优解含子问题最优解）；② 重叠子问题（所以填表而不是傻递归）；③ 状态转移方程（填空的核心就是它）。

例题：0-1 背包（软考出现频率最高）

背包容量 W=5，3 件物品：物品1(w=2,v=3)、物品2(w=3,v=4)、物品3(w=4,v=5)。求能装的最大价值。
状态转移方程（必须会默写）：
dp[i][j] = max( dp[i-1][j] , dp[i-1][ j-w[i] ] + v[i] )　（j ≥ w[i] 时）
含义："不装第 i 件"和"装第 i 件（腾出 w[i] 空间）"哪个值钱。
// 真题风格的 C 代码（挖空处已用 hl 标出）
int knapsack(int n, int W, int w[], int v[]) {
    int dp[N][M], i, j;
    for (i = 1; i <= n; i++)
        for (j = 0; j <= W; j++) {
            dp[i][j] = (1)  dp[i-1][j];                // 默认不装第 i 件
            if ((2)  j >= w[i])                       // 背包装得下才考虑装
                if (dp[i-1][(3)  j - w[i]] + v[i] > dp[i][j])
                    dp[i][j] = dp[i-1][j-w[i]] + v[i]; // 装第 i 件更优则更新
        }
    return dp[n][W];
}
填空技巧：看到 dp[i][j] 先写 dp[i-1][j]；if 条件几乎总是 j >= w[i]；递归引用处找"j 减去什么"。三空连着考是固定套路。

另两个高频 DP 递推式（认识即可）

题目状态转移方程
最长公共子序列 LCS相同：dp[i][j]=dp[i-1][j-1]+1；不同：max(dp[i-1][j], dp[i][j-1])
最大子段和b[j] = max( b[j-1]+a[j], a[j] )，答案为 max b[j]

⑤ 回溯法：试探 → 碰壁 → 退回来

// 例：N 皇后 —— 逐行放皇后，冲突就换列，本行无解就回退到上一行
int place(int row) {
    int col;
    if (row > n) { cnt++; return 1; }   // n 行都放完，找到一组解
    for (col = 1; col <= n; col++) {
        if (check(row, col)) {           // 剪枝：与前面行的皇后不冲突才试
            q[row] = col;
            place(row + 1);               // 递归试探下一行
        }                                  // 此处天然"回溯"：函数返回后 col++ 换位置重试
    }
    return 0;
}
回溯填空点：check 冲突条件（同列：q[k]==col；对角线：|q[k]-col| == |k-row|）、递归调用下一层、剪枝 if。对角线判断 |q[k]-col|==|k-row| 直接背。

⑥ 时间复杂度：代码填空后的必问 必考

代码形态 / 递归式复杂度典型题目
T(n) = T(n/2) + O(1)（每次砍一半，只递归一边）O(log n)二分查找
T(n) = 2T(n/2) + O(n)（砍一半×2，合并代价 n）O(n log n)归并排序、快速排序（平均）
T(n) = T(n-1) + O(1)（每次少一个）O(n)顺序查找、单层递推
T(n) = 2T(n-1) + O(1)（每次分两支全试）O(2ⁿ)回溯枚举子集
双层循环填 dp 表（物品×容量 / i×j）O(n×W)、O(n²)0-1 背包、LCS、最大子段和
展开法示范（看一遍就会）：T(n) = 2T(n/2) + n → 第 1 层合并代价 n，第 2 层两个子问题共 2×(n/2)=n，每层都是 n；要砍 log n 层才到 1 → 总代价 n × log n = O(n log n)。
复杂度大小排序（选择题直接用）：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)。问"最高/最低复杂度"就按这条链排。
