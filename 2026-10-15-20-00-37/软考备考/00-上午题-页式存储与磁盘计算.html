① 页式存储：到底在干什么？

一句话：把程序"切碎"，装进内存的"格子"里。程序觉得自己是连续的（逻辑地址），实际散落在内存各处（物理地址）——中间靠一张页表翻译。

为什么要这么干？内存用久了会"碎"成很多小空隙，整段程序装不进去；分页后每片 4KB 的小块见缝就插，外碎变内碎，利用率高。软考还爱考：页式管理没有外部碎片，但有内部碎片（最后一页常常装不满）。

② 地址转换：三步手算法 必考核心公式

物理地址 = 页帧号 × 页大小 + 页内偏移
1
页号 p = 逻辑地址 ÷ 页大小（取整）
2
页内偏移 d = 逻辑地址 mod 页大小（偏移不变！直接抄过去）
3
查页表：页号 p → 页帧号 f，拼装物理地址
十六进制小技巧（考试提速）：页大小 4KB = 0x1000，即地址的低 12 位是页内偏移、高位是页号。
所以物理地址 = （页表给出的页帧号）拼上（原地址的低 3 位十六进制），不用真的转十进制！

③ 页面置换：内存满了，谁出去？必考

三个算法就记一句口诀：FIFO 看谁先来，LRU 看谁最久没用，OPT 看谁以后最晚才用（OPT 是理论最优，考试当"下限"用）。每装入一个不在内存的页 = 缺页 1 次。

▶ 置换模拟器（访问序列：4,3,2,1,4,3,5,4,3,2,1,5　物理块 3 个）
缺页：0
当前内存块：[ 空, 空, 空 ]
算法本序列缺页次数口诀
FIFO（先进先出）9 次队列排队，最早进来的先走
LRU（最近最久未用）10 次谁最长时间没被访问谁走
OPT（最优置换）7 次往后看，谁以后用得最晚谁走
真题彩蛋（Belady 异常）：FIFO 算法下，物理块变多缺页反而可能变多——这是选择题干扰项常客；LRU 不可能出现该异常。

⑤ 磁盘计算：两个公式走天下 必考

公式一：存取时间

存取时间 = 寻道时间 + 旋转延迟 + 传输时间
平均旋转延迟 = 转一圈的时间 ÷ 2 = (60 / 转速rpm) ÷ 2
传输时间 = 读的数据量 ÷ 数据传输率（或 读几扇区 × 每扇区时间）
理解记忆：磁头先"跑过去"（寻道），再"等盘转到目标位置"（旋转延迟，平均等半圈），最后"数据转过去被读完"（传输）。三步接力。
▶ 磁盘时间计算器

转速 转/分　　寻道时间 ms　　每道扇区数 　　读 个扇区

公式二：磁盘容量

容量 = 磁头数(盘面数) × 每面磁道数 × 每磁道扇区数 × 每扇区字节数
例：16 磁头 × 100 磁道 × 20 扇区 × 512B = 163,840,000 B ÷ 1024² = 15.625 MB

⑥ 旋转优化"神题"：间隔存放 高频大题

经典设定：单缓冲，读完一条记录后 CPU 处理它时，磁盘还在继续转——处理期间磁头"飘"过了后面的记录，回来得再等一整圈。这就是时间的最大杀手。

条件数值
转速6000 转/分 → 转一圈 10ms
每磁道 10 条逻辑记录（均分）读 1 条需 1ms
每条记录处理时间3ms（单缓冲：读完才能处理）
考试变体：题目会问"为达到最优，记录之间应间隔多少个逻辑记录？"答：3 个（即隔 3 空 1，第 n 条与 n+1 条起点相距 4 个记录位置）。

⑦ 候选码：怎么求？必考

先弄懂 4 个词

1
函数依赖 X→Y：知道了 X，就唯一确定了 Y。如"学号→姓名"。
2
候选码：能唯一标识一行（元组）的最小属性集。"最小"指：少一个属性就不行了。
3
主码：候选码可能有多个，从中挑一个当主码。
4
主属性 / 非主属性：出现在任意一个候选码里的属性叫主属性；谁都不在的叫非主属性。

闭包 X⁺：求候选码的基本功

闭包是什么：从属性集 X 出发，反复执行"某条函数依赖的左部全在闭包里 → 把右部也加进来"，直到加不动为止，得到的就是 X⁺。若 X⁺ 包含了全部属性，说明 X 能推出一切 → X（或其超集）能唯一标识元组。
▶ 闭包计算器（固定 F = { A→B, B→C, D→E }）

输入属性集：　　

试试输入 AD，看闭包如何一步步长大 ↓

求解四步法（图形分类法，软考标准解法）

第一步：给属性分类（只看每条函数依赖，数某属性出现在箭头左边还是右边）
① L 类：只在左部出现 → 必在候选码中
② R 类：只在右部出现 → 必不在候选码中
③ N 类：左右都不出现 → 必在候选码中
④ LR 类：左右都出现 → 待定，需要试

第二步：先求 (L类 ∪ N类) 的闭包，若覆盖全部属性 → 它就是候选码；
第三步：否则，逐个/组合加入 LR 类属性再求闭包，能覆盖全部属性且"最小"的，就是候选码。

▶ 例 1（纯 L 类，一步到位）

R(A,B,C,D,E)，F = { A→B, B→C, D→E }
分类：L 类 = {A, D}；R 类 = {B, C, E}；无 N、无 LR。
求 (AD)⁺：初始 {A,D} → A→B 得 B → B→C 得 C → D→E 得 E → {A,B,C,D,E} 覆盖全部 ✓
候选码 = {AD}（唯一）。主属性：A、D；非主属性：B、C、E（后面范式判定要用！）。

▶ 例 2（含 LR 类，要试）

R(A,B,C)，F = { AB→C, C→B }
分类：L 类 = {A}；LR 类 = {B, C}；无 R、无 N。
① 先试 A⁺ = {A} ✗ 不够 → ② 加入 B 试 AB⁺ = {A,B} → AB→C 得 C → {A,B,C} ✓ → AB 是候选码
③ 再试 AC⁺ = {A,C} → C→B 得 B → {A,B,C} ✓ → AC 也是候选码
候选码 = {AB, AC}，此时 A、B、C 全是主属性。（记住这个例子，⑧ 节判定 BCNF 还要用它！）

⑧ 范式：一张表"规范化"到什么程度必考

范式就是层层加码的"合格标准"。考试通常给一张表 + 函数依赖，问你最高满足第几范式。核心只有两件事：找码 → 找坏依赖。

范式一句话要求消除什么坏依赖
1NF每个属性不可再分（原子性）表中有表 / 大字段
2NF1NF + 非主属性完全依赖候选码非主属性对码的部分依赖
3NF2NF + 非主属性不传递依赖候选码非主属性对码的传递依赖
BCNF每个决定因素（箭头左部）都必须包含某个候选码主属性之间的坏依赖
两个定义必须咬死：
① 部分依赖：码是联合的（如"学号+课程号"），但某个非主属性只依赖其中一半（姓名只依赖学号）。码是单属性时不可能有部分依赖——考试陷阱！
② 传递依赖：X→Y、Y→Z，且 Y 反推不出 X，则 Z 传递依赖于 X（如 学号→系→系主任）。

▶ 例 A：卡在 1NF（部分依赖）

R(学号, 课程号, 成绩, 姓名)，码 = (学号, 课程号)（联合码）
依赖：成绩 完全依赖联合码 ✓，但 姓名只依赖学号（半个码）→ 部分依赖 → 只到 1NF
拆法：R1(学号, 课程号, 成绩) + R2(学号, 姓名) → 都到 2NF

▶ 例 B：卡在 2NF（传递依赖）

R(学号, 系, 系主任)，码 = 学号（单属性，无部分依赖 → 自动 2NF）
依赖：学号→系，系→系主任 ⇒ 学号→(传递)→系主任 → 卡在 2NF
拆法：R1(学号, 系) + R2(系, 系主任) → 都到 3NF

▶ 例 C：3NF 但不是 BCNF（主属性闹事）

R(A,B,C)，F = { AB→C, C→B }，由 ⑦ 例 2 知候选码 = {AB, AC}，全是主属性，无非主属性
→ 3NF 管的是"非主属性"，这里没有非主属性 → 自动满足 3NF
→ 但 C→B 的左部 C 不包含任何候选码 → 违反 BCNF 的"左部必须含码" → 不是 BCNF
拆法：R1(A,B) + R2(A,C)（即把 C→B 拆出去）→ BCNF

▶ 判定流程图（考试照这个顺序问自己）

口诀："一化要原子，二化消部分，三化消传递，BC 看左部（左部必须含码）"。答题先写"候选码是谁、主属性是谁"，坏依赖就一目了然。

⑨ 高频计算总集（11 类，每类：公式 → 例题步骤 → 坑）考前必过

用法：这 11 类 + 前面 ①~⑧ 的页式/磁盘/候选码/范式 = 上午题全部高频计算（合计约 18~24 分）。每类三件套：公式 → 带数字的例题步骤 → 坑。考前一晚把每类的"坑"扫一遍即可。

1. 进制转换与码制（原/反/补/移码）

公式/规则：十进制→二进制：除 2 取余、倒序排列。正数：原码=反码=补码；负数补码=反码+1；移码=补码符号位取反（用于阶码）。
例：45 → 101101；−5 的 8 位补码：5=00000101 → 反码 11111010 → +1 → 11111011。
坑：8 位补码表示范围 −128 ~ +127（比原码多一个最小负数）；0 的补码唯一。

2. 浮点数：范围与精度（概念选择题）

规则：N = 尾数 × 2^阶码。表示范围由阶码位数决定，精度由尾数位数决定；规格化：尾数最高有效位为 1（1/2 ≤ |M| ＜ 1）。
例：同一机器阶码从 8 位增到 12 位 → 表示范围变大，精度不变（尾数没变）。
坑："范围/精度由谁决定"是最爱考的对调陷阱；补码/移码符号位方向相反。

3. 存储容量与芯片数

公式：芯片数 = (总字数 ÷ 单片字数) × (总位数 ÷ 单片位数)——字扩展与位扩展分开算再相乘。
例：组成 64KB 内存（地址 16 位），用 8K×4 位的芯片 → 字扩展 64K÷8K=8、位扩展 8÷4=2 → 16 片。
坑：8K×4 位的意思是 8K 个单元、每单元 4 位——别把 4 当 4K。

4. Cache 平均访问时间

公式：顺序访问式 T = H×t1 + (1−H)×t2；同时访问式 T = H×t1 + (1−H)×(t1+t2)。
例：H=90%，Cache 40ns，主存 200ns → 顺序式 = 0.9×40+0.1×200 = 56ns；同时式 = 0.9×40+0.1×240 = 60ns。
坑：题干"同时访问"四个字决定公式；命中率写小数别写百分号直接乘。

5. 流水线

公式：总时间 = 各段之和 + (n−1)×周期（周期=最长段）；吞吐率 = n÷总时间；加速比 = 不流水÷流水。
例：四段 1/2/3/4ns 跑 100 条 → 10 + 99×4 = 406ns；加速比 = 1000÷406 ≈ 2.46。
坑：第一条指令 = 各段之和；流水线周期 = 最长段。

6. 可靠性（串联/并联/MTBF）

公式：串联 R = R1×R2×…；并联 R = 1−∏(1−R)；混联先小后大；MTBF = 1/λ（λ=失效率），串联系统 MTBF 比单机短。
例：两组各 2 个 0.9 并联再串联 → (1−0.1²)² = 0.9801。
坑：并联可靠度一定高于组内任何一个；串联一定低于最差的部件。

7. 海明码校验位数

公式：2^k ≥ n + k + 1（n 数据位、k 校验位）；校验位放在 2^i 位置（1、2、4、8…）。
例：n=8 → k=4（2⁴=16 ≥ 13 ✓；k=3 时 8＜12 ✗）。
坑：奇偶校验/CRC 只能检错；能纠 1 位错的只有海明。

8. 子网划分

公式：可用主机 = 2^主机位 − 2；子网数 = 2^借用位数；广播地址 = 下一个子网地址 − 1。
例：192.168.1.0/26 → 主机位 6 → 62 台；广播地址 = 192.168.1.63；借 3 位 → 8 个子网。
坑：减 2；127.0.0.1 回环；169.254 自动专用。

9. 多媒体容量

公式：图像 = 宽×高×位深÷8；音频 = 采样率×量化位×声道×秒÷8；采样频率 ≥ 最高频率×2。
例：800×600、16 色 → 每像素 4 位 → 800×600×4÷8 = 240000B ≈ 234KB；44.1kHz、16 位、双声道、60 秒 → 44100×16×2×60÷8 ≈ 10.1MB。
坑："16 色"=4 位不是 16 位；JPEG 有损、PNG 无损。

10. 信道容量与调制速率（网络计算）

公式：尼奎斯特（无噪声）C = 2W·log₂V（W 带宽 Hz、V 码元种数）；香农（有噪声）C = W·log₂(1+S/N)；比特率 = 波特率 × log₂(码元种数)；采样定理：采样频率 ≥ 2×最高频率。
例：带宽 3000Hz、16 种码元 → 尼奎斯特 = 2×3000×log₂16 = 6000×4 = 24000bps；信噪比 30dB（S/N=1000）→ 香农 = 3000×log₂1001 ≈ 30kbps。
坑：dB 换算：10dB=10 倍（30dB=1000 倍，每加 10dB 多一个 0）；"16 种码元"每码元携带 log₂16=4 位。

11. UNIX 索引文件最大容量（文件系统计算）

公式：i-node 13 个地址项 = 10 直接 + 1 一级间接 + 1 二级间接（+1 三级）；每个间接块能存"块大小÷地址项大小"个地址（4KB÷4B = 1024 个）。最大文件 = (10 + 1024 + 1024²) × 块大小。
例：块 4KB、地址 4B → 最大 ≈ (10+1024+1048576)×4KB ≈ 4GB。
坑：直接块就 10 块（10×4KB=40KB，别乘 1024）；一级间接那个"间接块"本身也占一个块。

12. 小计算三连（循环队列 / 二分 / 对称矩阵）

循环队列：元素个数 = (rear − front + 容量) mod 容量。例：front=3、rear=8、容量 10 → (8−3+10)%10 = 5。
二分查找：最多比较 ⌈log₂(n+1)⌉ 次，前提顺序存储+有序。例：n=100 → 7 次。
对称矩阵压缩：存下三角共 n(n+1)/2 个元素（含主对角线）。
坑：循环队列必须加容量再取模；二分的前提"有序+顺序存储"少一个都不行。
