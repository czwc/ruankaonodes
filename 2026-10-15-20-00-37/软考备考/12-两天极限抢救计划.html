今天 Day1 · 纯记忆日（上午 3h + 晚 1h）

▶ 第 1 块：知识产权（30 分钟 → 2~3 分，性价比之王）

这类题就是"一个发明/一段代码，保护几年？归谁？"，答案全是法条定的，背就完事：
① 你出钱找人写软件，没约定归谁 → 归"写的人"（受托方）。白话：付钱≠拥有，除非合同写了。
② 上班时间做出来的作品 → 归公司（职务作品）。白话：拿工资干的活，成果是老板的。
③ 著作权自动取得——写完那一刻权利就是你的，不用去登记，登记不是拿到权利的前提。
④ 专利保护期（从申请那天起算）：发明 20 年、实用新型 10 年、外观设计 15 年。记法："发明最值钱保最久 20；实用新型打折 10；外观 15 居中"。
⑤ 商标 10 年，到期可以一直续（无限续展）——所以老字号商标能用一百年。
⑥ 作者的财产权 = 活着 + 死后 50 年；署名权（作品署谁的名）永远有效没期限。
⑦ 商业秘密没有保护期限（保密多久保多久），而且别人自己"反向破解"出来是合法的——所以可口可乐配方靠保密不靠专利。

▶ 第 2 块：软件工程四小件（60 分钟 → 4~6 分）

【开发模型】"这个项目该按什么流程做"——题干描述往场景上套：
· 提到"风险分析" → 螺旋模型（每转一圈先做一次风险评估）
· "需求不清楚，先做个样品给用户看" → 原型模型（装修先出效果图）
· "分批上线、一期二期" → 增量模型（分栋交房）
· "按文档一步步来、每个阶段评审签字" → 瀑布模型（一步到底不回头）
· "每日站会、随时改需求" → 敏捷
【软件测试】分两种：黑盒 = 不看代码，只喂输入看输出对不对（像点外卖不看厨房）；白盒 = 打开代码，检查代码被执行得多仔细。白盒考"由弱到强的顺序"：
语句 → 判定 → 条件 → 判定/条件 → 条件组合 → 路径（路径最强=每条路都走到）。黑盒的三个方法：等价类 / 边界值 / 因果图（认词即可）。
【McCabe 复杂度】衡量代码有多绕的一个数，公式 = 边 − 点 + 2（"边"=流程图里的箭头，"点"=圆圈，数一数代入就行）。
【软件维护四种】软件交付后还要改，改的原因不同、名字不同：修 bug = 改正性；换了新系统/新环境要跟着改 = 适应性；加新功能 = 完善性（占全部维护的一半左右，最大头）；提前埋伏笔防患未然 = 预防性。
【耦合 & 内聚】耦合 = 模块（功能块）之间互相缠得多紧，越松越好；内聚 = 一个模块内部是不是干同一件事，越齐越好。考排序/判断：
耦合从最好到最差：数、标、控、公、内（数据→标记→控制→公共→内容）。判断题口诀：题干说"直接改别人模块里的数据" = 内容耦合（最差）；说"只传一个数值过去" = 数据耦合（最好）。
内聚从最好到最差：功、顺、通、过、时、逻、偶（功能→顺序→通信→过程→时间→逻辑→偶然）。

▶ 第 3 块：设计模式 9 题眼（30 分钟 → 2~3 分）

设计模式就是"前人总结的代码套路"，考法固定：题干描述一个场景，问你这是哪个模式。只背"看到什么词→选什么"：
· "全局只能有一个"（如一个系统只允许一个打印机管理器）→ 单例（全国只有一个主席）
· "一个变，所有跟着它的都自动收到通知" → 观察者（微信群：群主一发言全员收到）
· "不加子类就给对象加新功能" → 装饰器（手机壳：不换手机加功能）
· "算法/做法可以随时换一种" → 策略（导航：高速/不走高速随时切换）
· "行为跟着内部状态变（同一个按钮不同状态下干不同事）" → 状态
· "创建什么对象交给子类决定" → 工厂方法（点餐下单，后厨决定做什么）
· "中转/控制访问" → 代理（明星的事经纪人挡着）
· "步骤顺序固定，个别步骤子类自己定" → 模板方法（泡面流程固定，加不加蛋你定）
· "两个接口对不上，中间转一下" → 适配器（港版插头转换头）
另背两原则："不改旧代码就能加新功能" = 开闭原则；"子类能顶替父类用且不出错" = 里氏替换。

▶ 第 4 块：专业英语（40 分钟 → 3~4 分）

最后一大题是英语阅读填空（5 空），别通读全文，就两个套路：
套路① 先看选项词性（这词是名词/动词/形容词？），再回原文看空格前后搭不搭——空格前是 be 动词多半填形容词/分词，空格前是 the/形容词多半填名词。
套路② 固定搭配直接秒：be responsible for（负责）、be capable of（能够）、be applicable to（适用于）。介词对了就选它。
高频词 12 个（认识的跳过）：requirement 需求、specification 规格说明、maintenance 维护、integration 集成、object-oriented 面向对象、life cycle 生命周期、algorithm 算法、compile 编译、reliability 可靠性、security 安全性、encapsulate 封装、implementation 实现。

▶ 晚上加餐 1 小时：数据结构三条 + 操作系统三条（树没把握的，先花 30 分钟过一遍 13 篇·树零基础专讲，再回来背这三条）

【排序】口诀"快些选堆不稳定"= 快速、希尔、选择、堆这 4 种排序不稳定（"不稳定"= 两个相同的数排完可能换前后位置，考试只考"哪些不稳"这个分类），其余全稳定。
【树】叶子数 = 度为 2 的节点数 + 1（n0 = n2 + 1）。白话：每多一个"带俩下级的"（度为 2 的节点），就必多一个"光杆员工"（叶子=没有下级的节点）。不用推导，背等式直接算。
【二分查找】前提：数据已排好序且存在数组里（不能是链表）。最多比较 ⌈log₂(n+1)⌉ 次（⌈⌉=向上取整）。白话：猜数字游戏，每次猜中间扔一半，1000 个数最多 10 次。
【生产者消费者 · PV 操作】P = 申请一个资源（没有就等着）；V = 释放一个资源（通知别人能用）。设一个缓冲区（临时仓库）容量为 n，三个信号量初始值死记：empty = n（仓库空格子数，一开始全空）、full = 0（满格子数，一开始没货）、mutex = 1（仓库门锁，一次一人）。顺序口诀："同步在前、互斥在后"——先 P(empty) 再 P(mutex)，写反了会死锁（考这个！）
【进程三态】就绪 = 排队等 CPU 叫号；运行 = 正在跑；阻塞 = 等别的东西（等输入、等资源）跑不了。最常考的一句：阻塞态不能直接跳到运行态——必须先回就绪排队（考"以下哪个状态转换不存在"就选它）。时间片（轮流用 CPU 的份额）用完 = 运行→就绪。
【银行家算法】= 避免死锁（死锁=几方互相卡住都不放资源）。银行家=放贷前先盘算"借出去还能不能收回"，所以是"避免"策略，不是"预防"，选项别混。

明天 Day2 · 计算模板日（上午 3h + 晚 1h）

▶ 第 5 块：计算四件套（75 分钟 → 3~4 分，套模板不思考）

这四个是"套公式就出答案"的题，公式带例子背：
① 流水线：像洗衣机流水线——第一件衣服要走完全程，之后每 4 分钟就出一件。公式：总时间 = 各段时间加起来 + (条数−1) × 最长段。例：四段分别 1/2/3/4 纳秒，共 100 条指令 → 10 + 99×4 = 406ns。注意"最长段"= 最慢那段（这里 4）。
② Cache（高速缓存）：CPU 先去"小快柜"找数据，找到叫命中，找不到才去慢的大仓库（主存）。公式：平均时间 = 命中率×Cache时间 + (1−命中率)×主存时间。例：90%、40ns、200ns → 0.9×40 + 0.1×200 = 56ns。例外：题干说"同时访问"→ 第二项改成 (Cache+主存)。
③ 可靠性：串联（一个坏全停，像一节电池串一节）→ 相乘：两个 0.99 串联 = 0.99×0.99 = 0.9801；并联（有备份，两个全坏才坏）→ 1−(1−R)²：两个 0.9 并联 = 1−0.1×0.1 = 0.99。混联：先把小的并起来算成一个数，再串。
④ 子网（IP 地址切分）：/27 的意思是 IP 的前 27 位是"楼号"（网络），剩下 32−27=5 位是"门牌"（主机）。公式：可用主机数 = 2^门牌位数 − 2（减 2 是因为全 0 是楼号本身、全 1 是广播，不能分给人用）。例：/27 → 5 位 → 2⁵−2 = 30 台。

▶ 第 6 块：信息安全方向题 + 网络（60 分钟 → 3~5 分）

先懂一句打底：每个人都有"一对钥匙"——私钥（自己藏好，谁都不给）和公钥（随便发给别人）。用私钥做的事，全天下只有你能做（所以能证明"是我干的"）；用公钥加密的东西，只有配对的私钥能解开。懂了这句，方向题就是送分：
· 数字签名（防抵赖）= 发送方拿自己的私钥签，对方拿发送方的公钥验——因为私钥只有发方有，赖不掉。
· 保密 = 接收方的公钥加密，接收方自己用私钥解——别人拿到了也解不开。
· 摘要（MD5/SHA，给文件算个"指纹"）= 只保证完整性（没被篡改），既不保密也不防抵赖。
· 对称加密 = 加密解密用同一把钥匙，快，但钥匙怎么安全寄给对方是个难题，代表 AES / DES；非对称 = 公私钥一对，慢，代表 RSA / ECC。数字证书 = 权威机构 CA 盖章证明"这个公钥真是他的"。
攻击对号（看到描述选名字）：海量请求把服务器挤爆 = DDoS；往输入框塞 SQL 代码骗数据库 = SQL 注入；往网页里塞脚本坑浏览的人 = XSS；只能发现入侵报警的 = IDS，还能拦截的 = IPS。
网络认词：TCP = 可靠、要先"三次握手"（打电话先喂？在听。好，说事）；UDP = 快但不保证送到（群发短信）。DNS = 域名翻译成 IP（通讯录）；DHCP = 自动分配 IP（酒店前台发房卡）；ARP = 已知 IP 查 MAC（网卡的物理编号）。
端口（服务的门牌号，硬背）：FTP 21 / SSH 22 / Telnet 23 / SMTP 25（发件）/ DNS 53 / HTTP 80 / HTTPS 443 / POP3 110（收件）。
设备分层：交换机认 MAC = 链路层；路由器认 IP = 网络层；集线器只放大信号 = 物理层。

▶ 第 7 块：新技术 + 数据库送分（50 分钟 → 3~5 分）

新技术（认词连线题）：租服务器（光租机器自己装）= IaaS；租装好系统的环境 = PaaS；软件直接用 = SaaS（住出租屋/租毛坯/住酒店）。大数据 4V：量大、多样、快、价值密度低。AI 三类：有标注数据训练 = 监督学习；没标注自己分堆 = 无监督（聚类）；奖惩试错 = 强化学习（训练小狗）。去中心化 + 智能合约 = 区块链；开发运维一体化 = DevOps（CI/CD 是它工具链）。
数据库 5 条送分：
① 实体间"多对多"（m:n，如学生↔课程，一个学生选多门课、一门课多个学生）→ 必须单独建一张中间表，表的主键 = 两边的主键拼起来。
② 候选码 = 能唯一认出一条记录的最小属性组（"学号"可以，"姓名"不行因为会重名）。
③ 范式（表的规整程度）一句话：部分依赖（主键是两个拼的，有的字段只跟其中一半有关）没解决 = 没到 2NF；传递依赖（A 管着 B、B 又管着 C，C 就该搬走）没解决 = 没到 3NF。
④ SQL 分组后的条件用 HAVING（"每组平均分>80 的组"），单行的条件用 WHERE。
⑤ 把自己的权限再转送给别人 = 授权语句末尾加 WITH GRANT OPTION。

下午题保底（每天 1 小时，只保 3 道必答）

目标：数据流图 + 数据库 + UML 三题拿 30+，算法/Java 蒙分。每天做 1 道，按模板写：
① 数据流图（画"数据怎么在系统里流动"的图）三件套：补外部实体（人/部门，画方块——看箭头从谁出发到谁结束）；补数据流（箭头，找"只进不出"的黑洞——一个加工只有数据进没有数据出，或反过来，必有缺）；父子平衡（父图=全景简图，子图=把某个加工放大细画；父图上有几条进几条出，子图加起来必须一样多）；加工名字格式 = 动词+名词（如"审核订单"）。
② 数据库大题四步：从题干动词判断关系（"一个…多个…"=1:n；"互相都能多个"=m:n）→ m:n 单独建表 → 标主键外键（外键 = 别人家的主键拿过来当联络字段）→ SQL 填空先看有没有"每组/平均"字样定用分组+聚合。
③ UML（画类和关系的图）认线条：三角实线 = 泛化（就是"继承"，猫 is-a 动物）；三角虚线 = 实现（落实接口承诺）；菱形画在"整体"那端：空心菱形 = 聚合（松散集体，班级散了学生还在），实心菱形 = 组合（同生共死，人没了心脏也没了）；include 箭头指向被包含的（每次都必做），extend 方向反过来（偶尔才做，可选）。最后一问 = 设计模式，套三句话："模式名 + 场景理由 + 对应类名"。
④ 算法/Java：按空给分 + 下拉选词——循环边界、递归出口、返回值这些"顺眼空"先填；变量类型对不上的选项先排除；空着必 0 分，蒙也要选。目标抢 5~10 分。
