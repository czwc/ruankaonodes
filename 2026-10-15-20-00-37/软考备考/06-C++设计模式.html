② 策略模式 C++ 版（与 05 的 Java 版逐行对照）核心

// 抽象策略：纯虚函数（= 0）使类成为抽象类，不能实例化
class PaymentStrategy {
public:
    virtual void pay(int amount) = 0;        // ★挖空1：纯虚函数 = 0
    virtual ~PaymentStrategy() {}             // 虚析构（好习惯，偶考）
};
class AliPay : public PaymentStrategy {       // ★挖空2：public 继承
public:
    void pay(int amount) { /* 支付宝支付 */ }
};
class WechatPay : public PaymentStrategy {
public:
    void pay(int amount) { /* 微信支付 */ }
};
class CashContext {                           // 环境类：与 Java 版结构相同
private:
    PaymentStrategy* strategy;                // ★挖空3：持有抽象类型【指针】
public:
    void setStrategy(PaymentStrategy* s) { strategy = s; }
    void checkout(int amount) {
        strategy->pay(amount);                // ★挖空4：指针用 -> 调用
    }
};
// 使用：CashContext ctx; ctx.setStrategy(new AliPay()); ctx.checkout(100);
C++ 版四连挖：① 纯虚函数 virtual ... = 0；② 继承时的 public；③ 成员是指向抽象类的指针；④ 指针调用用 ->。这四处在历年 C++ 卷里反复出现。

④ 装饰器 C++ 版（与 05 的 Java 版逐行对照）第二高频

class Coffee {
public:
    virtual double cost() = 0;                 // ★抽象构件：纯虚函数
    virtual ~Coffee() {}                        // 虚析构（好习惯）
};
class SimpleCoffee : public Coffee {           // 具体构件
public:
    double cost() { return 10.0; }
};
class CoffeeDecorator : public Coffee {        // 装饰器：也继承 Coffee
protected:
    Coffee* coffee;                             // ★核心挖空：持有同类型【指针】
public:
    CoffeeDecorator(Coffee* c) : coffee(c) {}   // ★构造初始化列表
    double cost() { return coffee->cost(); }    // 默认委托
};
class Milk : public CoffeeDecorator {          // 具体装饰器：继承装饰器
public:
    Milk(Coffee* c) : CoffeeDecorator(c) {}     // ★挖空：调父类构造
    double cost() { return coffee->cost() + 2.0; }  // ★委托 + 加价
};
// 使用：Coffee* c = new Milk(new SimpleCoffee()); → 12.0
C++ 装饰器四连挖：① 基类纯虚 cost() = 0；② 装饰类成员是 Coffee* 指针；③ 构造函数初始化列表 coffee(c) 或调父类构造 CoffeeDecorator(c)；④ 委托调用 coffee->cost() 再加料。与 Java 版结构完全同构，只是多了指针与初始化列表。

⑥ 考场执行清单

1
看类图定模式（同 05 的速查表），第一空通常问模式名。
2
看到"virtual ... ( ) = 0"型空 → 填 virtual 或 0；看到继承冒号后 → 填 public。
3
指针变量调用成员 → ->；对象变量 → .；看变量声明是 X 还是 X*。
4
环境类成员类型 = 抽象策略类指针（PaymentStrategy*），new 出的具体类赋给它。
5
类外定义成员函数时记得 类名:: 前缀，如 void AliPay::pay(int amount) {}。
