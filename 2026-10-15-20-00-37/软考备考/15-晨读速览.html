🎯 预测例题实战（先自己做，点开对答案）约 20 分钟 · 树 4 题+计算 4 题+对号 6 题

为什么是这 14 题：按近五年题型频率出的仿真题——树是你的最弱点（4 题强化），计算和概念对号覆盖上午剩余失分面。错哪题就回对应详解页重看那一小节。
🌳 树 4 题（你的最弱点）：
树1：某二叉树有 7 个叶子节点，度 2 的节点有几个？
6 个——n0 = n2 + 1（来历：总边数 n1+2n2 = 节点数−1 = n0+n1+n2−1，消去 n1）。7 个叶子 → n2 = 6。
树2：前序 ABDECF、中序 DBEAFC，求后序？
前序第一个 A 是根，回中序把 DBEAFC 切成左 DBE、右 FC → 左子树根 B（D、E 是它的左右孩子）、右子树根 C（F 是左孩子）→ 后序（左右根）= DEBFCA。易错：每层都要"回前序找根"，不是只切一次。
树3：100 个节点的完全二叉树，高度是几？
7 层（⌈log₂101⌉ = 7；因为 2⁶=64 < 100 ≤ 127=2⁷−1）。易错：64 个节点才是 6 层，100 已经要第 7 层了。
树4：四个叶子权 2、3、4、5 的哈夫曼树，带权路径长度 WPL = ?
合并：2+3=5 → 4+5=9 → 5+9=14（根）。深度：5 在第 1 层、4 在第 2 层、2 和 3 在第 3 层 → WPL = 5×1+4×2+2×3+3×3 = 5+8+6+9 = 28。易错：每轮挑"当前最小"的两个；权小的叶子离根最远。
🧮 计算 4 题：
计1：流水线四段 2/3/4/5ns，跑 50 条指令，总时间？
各段之和 = 14ns；周期 = 最长段 = 5ns；总时间 = 14 + 49×5 = 259ns。（第一条 = 各段之和，别乘周期）
计2：Cache 命中率 90%，Cache 50ns、主存 450ns，"同时访问"式平均时间？
T = 0.9×50 + 0.1×(50+450) = 45 + 50 = 95ns。（题干有"同时访问"→ 未命中那次把 Cache 时间也搭进去）
计3：子网掩码 /28，每个子网可用主机数？
主机位 = 32−28 = 4 → 2⁴−2 = 14 台。（减 2：网络地址+广播地址）
计4：32 位数据用海明码校验，需要几位校验位？
6 位。2^k ≥ n+k+1：k=6 → 64 ≥ 32+6+1=39 ✓；k=5 → 32 < 38 ✗。
🔎 对号 6 题（概念题，看到字眼就选）：
对1："窗口大小改变时，所有依赖它的视图自动刷新" → 什么模式？
观察者模式（状态变化自动通知所有依赖者；识别词 attach/notify/update）。
对2："订单从待支付→已支付→已发货，不同阶段行为不同" → 什么模式？
状态模式（行为随内部状态改变；与策略的区别：状态是对象自己切换，策略是外部换）。
对3："同一份数据导出 Excel/PDF/HTML 多种格式，可随时新增格式" → 什么模式？
策略模式（算法/做法可替换；"可随时新增"= 对扩展开放）。
对4：成绩表插入一个"学生表中不存在的学号" → 违反什么？
参照完整性（外键必须在对表中真实存在；插入重复主键才是违反实体完整性）。
对5：员工离职时拷走公司开发的源码继续使用 → 侵权吗？
侵权——职务作品/软件的著作权归公司，源码是公司资产，离职带走使用即侵犯著作权（个人只保留署名权这类人身权利）。
对6："单源最短路径按路径长度递增次序逐个确定顶点" → 什么策略？
贪心（每次抓当前最优、绝不回头；Dijkstra/Prim/Kruskal/哈夫曼 全家都是贪心）。

A. 上午 · 铁打结论 8 分钟

  1. 开发模型：风险→螺旋｜需求不明→原型｜分批交付→增量｜文档评审→瀑布｜每日站会→敏捷
  2. 白盒覆盖由弱到强：语句＜判定＜条件＜判定/条件＜条件组合＜路径
  3. McCabe：V(G) = 边−点+2 = 判定节点数+1 = 独立路径条数
  4. 耦合由好到差：数标控外公内；内聚由好到差：功顺通过时逻偶
  5. 设计模式：唯一实例→单例｜自动通知→观察者｜动态加职责→装饰器｜算法可换→策略｜状态变行为→状态｜创建延迟到子类→工厂方法
  6. 流水线：总时间 = 各段之和 + (n−1)×最长段；第一条=各段之和；加速比=不流水÷流水
  7. Cache：顺序式 T=H·t1+(1−H)·t2；"同时访问"第二项变 (1−H)×(t1+t2)
  8. 可靠性：串联相乘、并联 1−∏(1−R)、混联先小后大；MTBF=1/λ
  9. 页式转换：页号=商、偏移=余数；物理地址=帧号×页大小+偏移（帧号查表！）
  10. 缺页置换：FIFO=最早进先换、LRU=最久未使用先换
  11. 排序：不稳定="快些选堆"（快排/希尔/选择/堆）；一趟定位置：冒泡/选择/堆/快排能，插入/归并不能
  12. 二叉树：n0=n2+1；前序+中序唯一重建（前+后不行）；哈夫曼 2n−1 无度 1
  13. 循环队列元素 = (rear−front+容量) mod 容量；二分最多 ⌈log₂(n+1)⌉ 次（有序+顺序存储）
  14. 子网：可用主机=2^主机位−2；/26→62；127.0.0.1 回环；169.254 自动专用
  15. 端口：FTP21 SMTP25 DNS53 HTTP80 HTTPS443 POP3 110
  16. IP 分类：A 1~126、B 128~191、C 192~223；设备：集线器物理、交换机链路、路由器网络
  17. TCP=打电话可靠（网页邮件）；UDP=广播快（视频语音 DNS）；三态转换不存在的是阻塞→运行
  18. 范式：部分依赖挡 2NF、传递依赖挡 3NF；单属性候选码自动 2NF
  19. 安全四对四：保密→加密｜完整性→摘要｜防抵赖→签名｜身份→数字证书
  20. 签名用"发方私钥"，保密用"收方公钥"；IDS 只报警、IPS 能阻断；病毒寄生/木马后门/蠕虫自复制
  21. 知识产权：委托无约定归受托方、职务归公司、登记≠取得著作权；发明20/实用新型10/外观15（自申请日）；商标10 可续
  22. 云与新技术：租硬件 IaaS、租环境 PaaS、用成品 SaaS；区块链=去中心化+智能合约；大数据 4V
  23. OO 三类对象：边界管接口、控制管逻辑、实体管数据；图遍历：矩阵 O(n²)、邻接表 O(n+e)；DFS 栈、BFS 队列
  24. 海明：2^k≥n+k+1（8 位→4 位）；能纠 1 位错的只有海明，CRC/奇偶只检错
  25. 专业英语：先判词性，只读空格前后一句，不读全文

🇬🇧 英语临时抱佛脚（5 分抢救包）

题型固定：150 词左右技术短文挖 5 空、四选一，主题 90% 是软件开发/软件工程。这 5 分靠"猜"——方法是词性 + 搭配 + 主题词族，不需要读懂文章。
三步猜法（每题 30 秒）： ①判词性：空前是 the/a/an → 填名词；空前是 to/can/must/should → 填动词原形；空前是介词（of/in/for/by）→ 填名词/动名词；空后直接跟名词 → 填形容词；主语后缺谓语 → 填动词。
②找搭配：be used to / in order to / based on / consist of / be responsible for / such as——选项能接上搭配的优先。
③排除：词性不对的先划掉，剩下按主题词族选。

B. 计算公式 9 条 3 分钟

  1. 流水线：总 = 各段和 + (n−1)×最长段；加速比 = n×各段和÷总时间
  2. Cache：T = H·t1+(1−H)·t2（同时式第二项加 t1）
  3. 可靠性：串联乘；并联 1−(1−R)^n；混联先小后大
  4. 子网：主机位=32−前缀；可用=2^主机位−2；广播=段尾
  5. 页式：物理 = 帧号×页大小+偏移（页号=商、偏移=余）
  6. 海明：2^k ≥ n+k+1（8 位→4 位）
  7. 磁盘：平均存取 = 寻道 + 半圈(60000/rpm÷2) + 传输
  8. 图像 = 宽×高×位深÷8（16色=4位）；音频 = 采样率×位×声道×秒÷8
  9. 复杂度 5 长相：单层 i++→n｜i*=2→log n｜两层独立→n²｜外层n内层log→nlogn｜2T(n/2)+O(1)→n、+O(n)→nlogn

C. 口诀速查 2 分钟

  • 耦合：数标控外公内（内容最差）｜内聚：功顺通过时逻偶（偶然最差）
  • OSI 七层：巫师忘传会赢死（从下往上）

⭐ 数据流图 · 起点终点三步法（问题 3 专用，4 分）：
① 定名：缺的流名 = 题干里"说了但图上没画"那句的原词，别自己编；
② 定两端（按数据身份三选一）：规则/记录类 → D存储→加工（用规则去库里拿）；结果/输出类 → 加工→下一个加工或实体（算完送出去）；请求/输入类 → 实体→加工（人发起的）；
③ 校验：加工必有进有出；存储被写必被读（发现只有写入的 D，缺的读出流就是答案）；实体和存储之间不能直接连线（中间必隔加工）。
答题格式：名称（起点→终点），写"编号+名称"——如"监控处理规则（D1→P4）"，只写 D1→P4 不给满分。

D. 下午 · 模板速记 4 分钟

  1. 数据流图：缺失流 = 题干原词 +（起点→终点）；规则类从 D 读出、结果类从 P 发出、请求类从 E 进来；加工命名=动词+名词；存储必读写平衡
  2. 数据库：m:n 独立建表（联合主键+两端都是外键）；1:n 并入 n 端；"成绩/数量"挂联系上；候选码=只在依赖左边出现的属性（1 个候选码 AC ≠ 2 个候选码）；关系代数：σ挑行 π挑列 ⋈拼表（列号在连接后宽表里从 1 数）
  3. UML：三角=泛化/实现、空心菱=聚合、实心菱=组合（菱形在整体端）；include 必选、extend 可选方向相反；最后一问 = 模式名+场景理由+类名对应三句话
  4. Java 五形状：接口空=抄实现类签名(分号结尾)；new 空=照类图 new 具体类；类型空=右边 new 的类；调用空=对象.方法；构造参数=传上下文对象。最坏照抄类图也有 6 分
  5. 算法四形状：循环边界(i>=1/i<=n)、交换三连(R[1]=R[0])、函数调用(抄函数名)、比较条件(套题干规则)；复杂度数循环长相；25 分钟封顶就走
🥷 Java 邪修 · 纯抄流（完全看不懂代码时，6 条铁律照抄就能拿分）：
核心原理一句话：答案 100% 就在题目里——类图、上下文代码、题干词。不用懂，会找会抄就行。
① 空在 interface 里 → 抄实现类里同名方法那一行，去掉大括号、改分号结尾（实现类就在填空下方几行，照着抄签名）；
② 空在 = 右边 → new + 类名(参数)：类名照类图抄，参数照上下文已出现的变量名抄；
③ 空在 = 左边 → 抄右边 new 的那个类名；
④ 空在方法体里单独一行 → 找"哪个对象的方法还没人调用" → 对象.方法(参数照抄)；
⑤ 空在调用的括号里 → 抄上下文已声明的变量名原词；
⑥ 全不会 → 把全卷出现次数最多的类名/方法名抄进空里（答案词在卷面至少出现 2 次）。
交卷前三查：①接口里的空有分号吗；②类名大小写和类图一致吗（ConcretePatient ≠ Concretepatient）；③左接口右 new 实现，形状配对吗。
