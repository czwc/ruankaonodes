2025下原题大顶堆判断 + 堆的应用
下列哪个序列是大顶堆？ A. 9,7,8,3,5,6,4　B. 8,9,7,3,5,6,4　C. 9,7,8,3,10,6,4　D. 9,7,8,3,5,6,12
答案：A —— 大顶堆只要求每个爹 ≥ 俩孩子。B 根 8<9 ✗，C 中 7<10 ✗，D 中 8<12 ✗。
关联原题（2024下）：从 1000 个数里选最大的 10 个，用什么排序最合适？堆排序（只维护 10 大小的堆，不用全排）。
两场都考堆，明天大概率还有一道。
2025上原题页面置换 Belady 异常
页面置换中，Belady 异常（分配的块变多、缺页反而变多）不会出现在（）？
答案：LRU（B） —— LRU 属于栈式算法，绝不出现 Belady 异常；FIFO 会。OPT 也属于栈式算法但考题标准答案是 LRU/FIFO 二选一时选 LRU。
2025下又考了"最少访问原则删哪页"——页面置换连考三场，LRU 手算必练。
2025上原题 + 2025下原题数字签名 / 哈希算法（安全加重）
（2025上）数字签名中，发送方使用（）？ 发送方私钥签名（B），接收方用发送方公钥验证。
（2025下）下列哪个算法用了哈希？SHA256 / ECC / RSA / DES SHA256（信息摘要，不是加密）。
2026上安全题加到 2~3 道，签名/CA/摘要三件套是明天的铁定考点。
2025上原题 + 2025下原题事务隔离级别
（2025上）隔离级别安全性最高的是？ SERIALIZABLE（串行化）。
（2025下）要避免脏读，事务隔离级别至少设为？ READ COMMITTED（读已提交）。
记忆链：读未提交（有脏读）→ 读已提交（解决脏读）→ 可重复读（解决不可重复读）→ 串行化（全解决）。连考两场，第三场概率极高。
2025下原题 + 2025上原题流水线计算
（2025下）指令三段 2ns、2ns、1ns，流水线执行 100 条的总时间？
答案：5 + 99×2 = 203ns（第一条走全程 5，之后每 2ns 出一条，周期=最长段）。
变式：吞吐率 = 指令条数 ÷ 总时间 = 100/203；最大吞吐率 = 1/2ns。
2026上流水线/Cache 又是重点——这个公式四场里基本场场见。

2024下原题度为 3 的树求叶子数（树专项原题）
一棵度为 3 的树，有 5 个度为 1、4 个度为 2、2 个度为 3 的节点，叶子数？
答案：n₀ = n₂ + 2n₃ + 1 = 4 + 2×2 + 1 = 9（通用公式：n₀ = Σ(度−1)×n_度 + 1，二叉树就是它的特例 n₀=n₂+1）。

2024下原题磁盘调度 / 折半查找 / 补码

📦 计算机组成（押 5 道，预计 6~8 分）

★★★★★押A1 · 浮点数表示：阶码与尾数
浮点数的表示范围和精度由什么决定？
阶码越长范围越大；尾数越长精度越高。运算顺序：对阶（小阶向大阶看齐，尾数右移）→ 尾数运算 → 规格化。
2025下、2025上都考了浮点数，模板必背。
★★★★☆押A2 · 补码表示范围与特殊值
8 位补码能表示的范围？−128 ~ +127。陷阱：10000000 补码真值 = −128（没有对应的原码）；11111111 = −1；正数三码合一。
2024下考原码、2025下考补码关系，换汤不换药。
★★★★☆押A3 · Cache 命中率计算
Cache 20ns、主存 200ns、命中率 95%，平均访存时间？
0.95×20 + 0.05×200 = 29ns。若题目给「同时访问」方式则为 0.95×20+0.05×(200+20)，看题干措辞。
2026上明确 Cache 仍是重点。
★★★☆☆押A4 · DRAM vs SRAM
正确叙述组合？DRAM 集成度高、需刷新、便宜、做主存；SRAM 快、不用刷新、贵、做 Cache。单管 vs 六管。
2026上原题，存储层次年年有题。
★★★☆☆押A5 · 中断 / 寻址方式 / 指令寄存器
① 程序查询最慢、中断其次、DMA 最快且不占 CPU；② 寻址速度：立即 > 寄存器 > 直接 > 间接；③ PC 存下一条指令地址，IR 存正在执行的指令；④ 指令 = 操作码 + 地址码。
希赛考前 20 问第 1 问就是 PC/IR，寄存器 2024下考过。
★★★☆☆押A6 · 编译 vs 解释（希赛20问第9问）
编译：整体翻译成目标代码后执行，效率高，报错在编译期；解释：边翻译边执行、不生成目标代码，效率低但可移植性强（2025下原题）。Java = 编译+解释混合（先字节码后 JVM）。语义错误编译器查不出（2025下考了语义错误）。
四场高频轮换 + 希赛押题双确认。

📦 操作系统（押 6 道，预计 5~7 分）

★★★★★押B1 · PV 操作初值与顺序
生产者-消费者，缓冲区容量 n，empty/full/mutex 初值？empty=n，full=0，mutex=1。
陷阱题「能否交换两个 P 的顺序」→ 不能，可能死锁（先 P(mutex) 再 P(empty)，仓库满时抱着锁等格子）。
2026上 PV+死锁"很多考生觉得绕"——记住这个陷阱就能反杀。
★★★★☆押B1+ · PV 一定要成对吗？（希赛20问原题）
PV 操作都必须要成对出现吗？
互斥场景必须成对（P申请V释放，保护临界资源）；同步场景可以不成对（多个 P 对一个 V、靠信号量表达先后顺序）。
希赛 20 问第 8 问原样——概念辨析题，答"不一定"就赢了一半。
★★★★☆押B2 · 死锁四条件与预防
互斥、保持并等待、不剥夺、循环等待——破坏任一条件可预防；"互斥条件不能破坏"是经典陷阱。死锁处理策略强弱：预防 < 避免（银行家）< 检测恢复。
2026上考死锁避免，银行家算法"安全性检查"认得名字即可。
★★★★☆押B3 · 三态模型
运行→阻塞、阻塞→就绪的触发条件？
运行→阻塞=等资源/等I/O；阻塞→就绪=等到了（被唤醒）。不存在"阻塞→运行"和"就绪→阻塞"——醒来必须先排队。
2025下考了三态模型，送分。
★★★☆☆押B4 · 磁盘存取时间 / 调度
存取时间 = 寻道 + 旋转延迟 + 传输。SSTF 按最近磁道服务；SCAN 电梯式单向扫。
2024下 SSTF 原题（每磁道 6ms）、09 页例 11 有一模一样的模板。
★★★☆☆押B5 · SPOOLing / 文件系统
SPOOLing = 用磁盘把独占设备改成共享的虚拟设备（解决 CPU 与设备速度不匹配），2025下原题。文件目录 = 文件控制块（FCB）的有序集合；位示图 = 一个位管一个块（先圈"从 0 还是 1 编号"）。
文件系统 2024下、位示图年年轮换。

📦 数据结构与算法（押 7 道，预计 7~10 分，你的专项）

★★★★★押C1 · n₀=n₂+1 与度 3 树推广
二叉树 5 个度 2 节点 → 叶子？6。度 3 树：n₀ = n₂+2n₃+1（2024下原题答案 9）。
13 页第 2 课原话，四场连考树。
★★★★★押C2 · 前序+中序还原 / 哈夫曼 WPL
前序首=根，中序切两半，递归拼接（例：前序 ABDECF + 中序 DBEAFC → 后序 DEBFCA）。哈夫曼：每次合并最小俩，WPL = 每次合并和相加（验算法）。哈夫曼树没有度为 1 的节点；n 个叶子的哈夫曼树共 2n−1 个节点。
2024下哈夫曼"连考三年"、2025下又考——13 页全练过。
★★★★☆押C3 · 折半查找
mid=(low+high)/2 向下取整；n 个元素最多比较 ⌈log₂(n+1)⌉ 次（15 个数最多 4 次）；前提：顺序存储 + 有序。
2024下原题（20 个数查第 13 位）、2025下考了二分查找——14 页例 19 三句话。
★★★★☆押C4 · 排序稳定性与复杂度
稳定（相等不打架）：冒泡、插入、归并、基数；不稳定：快些选堆（快排/希尔/选择/堆）。快排一趟：基准 5 归位后左小右大，如 [2,3,1,4,5,7,8,6]（2025下原题）。归并/堆 nlogn，快排最坏 O(n²)。
"快些选堆"四场场场沾边。
★★★☆☆押C5 · 图：拓扑 / 最小生成树 / 关键路径
拓扑排序：每次输出入度 0 的点，输出后擦出边；AOV 网有环则无拓扑序。最小生成树：Prim 点入手、Kruskal 边入手，都不能有环。关键路径 = 最长路径，决定工期；活动最早开始=前序事件最早+耗时，最晚=后序最晚−耗时（2024下、2026上都考关键路径/活动图）。
图论连考，09 页例 16 拓扑 + 关键路径口诀。
★★★☆☆押C6 · 算法策略对号
分治=子问题独立（归并/快排/二分）；动态规划=子问题重叠有记忆（背包/最长公共子序列）；贪心=局部最优不回头（哈夫曼、最小生成树）；回溯=试探+悔棋（N皇后、八皇后）。
2025下上午考策略对号、下午考 N皇后回溯、2026上下午考贪心——这张对照表两头通吃。
★★★☆☆押C7 · 栈队列 / 矩阵 / 循环队列
栈=后进先出（函数调用/递归/表达式求值）；队列=先进先出（BFS/打印排队）。循环队列队满：(rear+1)%n == front，元素数=(rear−front+n)%n。三对角矩阵按行存储下标映射（2025下考了）。
循环队列/特殊矩阵隔年出，扫一眼公式即可。

📦 数据库（押 5 道，预计 5~7 分）

★★★★★押D1 · 范式判断（半把钥匙/传话链）
R(学号,姓名,系名,系主任)：主键单字段无半把钥匙问题，但 学号→系名→系主任 是传话链 → 2NF。"每个非主属性完全函数依赖于主键" → 2NF（2026上原题）。3NF = 消除传递依赖。
你已专门攻克，12 页范式三步走卡。
★★★★☆押D2 · SQL 关键字
分组后条件用 HAVING（行条件才是 WHERE）；模糊匹配 LIKE '_' 单字符 '%' 任意；去重 DISTINCT；聚合 COUNT/SUM/AVG；嵌套 IN / EXISTS。授权末尾 WITH GRANT OPTION = 可转授。
2025下考了 SQL 语句，年年必有 1~2 空。
★★★☆☆押D3 · 关系代数
选择 σ=挑行、投影 π=挑列、连接⋈=拼表（自然连接去同名列）、除法÷=「对所有都」的查询。π 投影会产生去重。
2025下考关系代数，符号认得就得分。
★★★☆☆押D4 · 视图与索引
视图=虚表（存的是查询定义不是数据），好处=简化查询+安全隔离。索引加快查询但拖慢插入/删除/修改、占空间（2025下考了索引错误项：选"提高增删改效率"为错误）。
2025下原题，数据库杂项区固定出题点。
★★★☆☆押D5 · ACID 与故障恢复
原子性A、一致性C、隔离性I、持久性D。日志先写（WAL）； COMMIT 后断电数据不丢=持久性。共享锁S（读）兼容S，排他锁X（写）谁都不兼容。
2025下考了 ACID/摘要，补上这个闭环。
★★★☆☆押D6 · 分布式数据库透明（希赛20问第18问，冷门但官方点名）
分布式透明 = 用户不必知道数据在哪：分片透明（最高层）→ 位置透明 → 局部映像透明，三层由高到低；实现难度越大透明级别越高。
我四场考频里没有它，但希赛 20 问专门列了——官方资料点名的冷门点最值得花 2 分钟。

📦 计算机网络（押 4 道，预计 4~6 分）

📦 补漏卡 · 对照官方考纲终检新增（这些是分值表里固定有、上面没覆盖的）

★★★★☆押J1 · 后缀表达式（中缀转后缀）
考试给 A+B*C 这类式子问后缀。口诀：按优先级加括号 → 把运算符挪到对应括号后面 → 去括号。
例：(A+B)*C → 后缀 AB+C*；A+B*C → 先算 B*C → ABC*+。逆波兰=后缀、波兰=前缀，别反。
程序语言+计组交叉必考位，两年内两场都考过表达式相关题。
★★★☆☆押J2 · 校验码：海明码 / CRC
海明码：2^k ≥ n+k+1 定校验位数——64 位数据问至少几位校验：k=7 时 128≥64+7+7=78 成立，答 7（记结论：64 位数据海明校验需 7 位）。CRC：模 2 除法（异或不借位），信息位后补 r 个 0 再除生成多项式，余数就是校验位。可纠正一位错的是海明码，只能检错的是 CRC/奇偶。
计组每年固定 1 题，公式会套就白送。
★★★☆☆押J3 · 传值 vs 传址 + 编译三件套
传值=复印一份给函数，改了不影响原变量；传址=给他家门牌号，函数顺着地址改的就是原件。考题给代码段问输出——看到 *p 解引用/数组参数就是传址会改原值。
编译 vs 解释：编译=整本翻译成目标程序再跑（生成目标代码、可独立执行）；解释=同声传译边翻边跑（不生成目标程序、慢但跨平台）。中间代码的作用=与机器无关、利于移植和优化。
程序语言每年 2~3 分，这三点就是全部主力。
★★☆☆☆押J4 · CMMI 与软件质量
CMMI 五级从低到高：初始→已管理→已定义→量化管理→优化（口诀"初管定量优"，中间"已"字辈俩）。软件质量特性：功能性最首要；可维护性=易修改；可移植性=换环境能跑；可靠性与容错相关。
软工记忆题常客，纯认脸分。
★★★☆☆押J5 · UML 多重度 + 关系代数除法
多重度符号：1=恰好一个、0..1=零或一、*=任意多个、1..*=至少一个。题干"一个部门有多个员工"→ 部门端写 1、员工端写 *——下午 UML 题标注多重度是官方点名的扣分点。
关系代数：π 投影（选列）、σ 选择（选行）、⋈ 连接（拼接）；除法 ÷ 考"全部/所有"类查询（查选修了全部课程的学生）。
多重度上午下午都考；关系代数每年 1 题。
★★☆☆☆押J6 · 总线 / 中间件 / 嵌入式一句话
总线三类：数据、地址、控制——地址总线单向（CPU→内存），宽度决定寻址空间；数据总线双向，宽度决定一次传多少位。中间件=分布式系统里"夹在中间帮忙传话的软件"（消息中间件=削峰解耦）。嵌入式交叉开发=宿主机编写编译 + 目标机运行调试。
计组/杂项偶考 1 题，一句话挡一下。

英语答题三招（不懂全文也能做）

③ 三选一排除法：先排除词性不对的，再排除语义相反的（如 positive/negative 二选一时看上下文有没有 but/however 转折）。五个空别空，选同一个词性顺眼的也有 2~3 分。

第四区 · 下午五题：怎么做 → 怎么拿分（逐题详解）

下午通用四条军规（阅卷老师复盘总结，先进脑子再进考场）：
① 先读问题再读材料——材料两三页，从头读到尾读完就忘。先看问什么（补实体？转关系模式？填类图？），再带着问题回材料找对应句子。
② 答案要具体，不写空话——材料里写"客户提交订单"，你的数据流就该叫"订单信息"，写"数据"两个字不给分；数据库题要落到表名、字段、主键。
③ 文字问答题用编号列表作答——照格式写：「1. 加工P2缺少输入数据流'XX'。 2. 数据存储D3只有流入没有流出。」一条一空，方便按点给分。
④ 绝不留白——数据流名、实体名按业务常识猜也写上；每空必填，空着才是真 0 分。
时间预算：开考通览全卷 3~5 分钟 → 每题 25~30 分钟 → 最后留 15 分钟检查补漏。单题超时立即跳，先易后难。
必考试题一 数据流图 · 目标 12~14 分 · 约 28 分钟 · 预测背景：AI/智能类业务
考什么（近两年问法就三种）：① 补外部实体/数据存储的名字；② 补缺失的数据流（起点+终点）；③ 用父子平衡说明图中错误。
三步拿分法：先圈外部实体（系统外的人/组织/外部系统，如用户、管理员、支付平台）→ 再圈加工（材料里的动词短语：提交订单、审核付款）→ 最后核对父子平衡：父图每个加工的输入输出流 = 子图展开后之和，多一条少一条就是答案。
答题格式示范（照抄这个句式）：「加工P3缺少输出数据流'审核结果'：该数据流从加工P3流出，流向外部实体E1/教师。」——来源加工 + 去向加工（或实体）两端都要写，2026 上这题大多数人只写一端丢一半分。
易错点：数据流名用名词（订单信息）、加工名带动词（审核订单），写反不给分；数据存储若"只有入没有出"必是错误（存进去没法查询）；不凭空造材料里没有的流。
送分小料：数据字典符号 { }=重复出现、[ ]=其中之一可选、..=取值范围。
必考试题二 数据库 · 目标 12~14 分 · 约 25 分钟 · 预测背景：共享/预约/管理平台类
考什么：① 补 E-R 图（实体/联系/属性）；② E-R 转关系模式并标主外键；③ SQL 填空；④ 偶尔问范式或"看到多个就拆表"。
三步拿分法：读材料把名词圈成实体、动词圈成联系（"学生选修课程"→学生—选修—课程）→ 按1:N 外键放 N 端、M:N 独立建中间表（两端主键拼组合主键）、联系若有自己的属性放中间表 → 标主外键：多方持外键，外键指向他表主键（2026 上这问"要格外仔细"，慢慢数）。
SQL 填空认字法：GROUP BY 后面的条件填 HAVING；统计个数 COUNT(*)、求和 SUM()；"包含全部/所有"用嵌套 IN 或 NOT EXISTS；空里填字段名就照题干给的属性名抄，别自己造。
易错点：多对多漏中间表；1:1 也可能"看参与约束"（必填端合并）；组合主键两个成员都要下划线。
必考试题三 UML · 目标 10~12 分 · 约 25 分钟 · 预测背景：订单/仓储/调度类；最后一问高频=策略模式
考什么：① 补类名/属性/方法名；② 判类关系（泛化/实现/聚合/组合/关联/依赖）；③ 标多重度；④ 最后一问设计模式+理由。
拿分法：补类图空 = 抄题干英文词（2025 下无人机题答案全是材料里的单词）。判关系看图和口诀：三角实线=泛化（继承"是一种"）、三角虚线=实现（"实现某接口"）、空心菱形=聚合（可独立活：班级散了学生还在）、实心菱形=组合（同生共死：订单没了订单项也没了）。多重度：题干"一个 X 对应多个 Y"→ X 端 1、Y 端 *。
最后一问模板（背熟直接抄）：「规则/算法不断扩充、可动态切换」→ 策略模式：将可变的算法封装成独立类，使它们可相互替换、新增算法不改原有代码，符合开闭原则；「状态改变行为」→状态模式；「状态变化自动通知多方」→观察者。
易错点：聚合组合选反（先问"部分能离开整体单独存在吗"）；include（必然包含）和 extend（偶尔扩展）混——用例箭头指向被包含/扩展的用例。
必考试题四 算法 · 目标 5~8 分 · 最后做 · 预测：贪心/DFS 回溯全新包装
先懂一个事实：2026 年起算法题刻意用全新场景，没人能提前背到原题——所以你的目标不是做出来，是把"结构分"拿走。
第一问（策略判断）是白送分：思想全写在题干文字里——「每次选当前最优」=贪心；「分解成子问题、保存中间结果」=动态规划；「尝试→不行就退回重来」=回溯；「折半/每次排除一半」=分治。读完题干文字第一问就能答，不用看代码。
代码空认五类：循环开头 i=0；递归出口填最小答案（1/n/−1）；累加 sum+a[i]；交换两空夹 temp；最后 return 填一路攒的变量。近两年官方认证失分重灾区=循环边界：拿不准就在 ±1 的选项里选"最普通"的那个。
若是 DFS/连通类：认三个词就够：visited[i]=1（标记走过）、dx/dy 四方向数组、函数里递归调用自己。
必考试题五/六 Java/C++ 二选一 · 目标 8~10 分 · 最后 30 分钟 · 预测池：观察者/策略/状态/装饰器
选哪道：果断选 Java——你背过六大高频模式骨架，类图+关键词就够；桥接（2025下）、原型（2026上）刚考过，今年大概率轮换回观察者/策略/状态/装饰器/组合。
做题顺序：① 读场景一句话定模式（"自动通知"=观察者、"可切换规则"=策略、"状态变行为"=状态、"动态加功能"=装饰器）；② 看类图：三角虚线=接口 → 类声明填 implements 接口名；③ 填空五件套：成员变量填接口名、通知循环填 update()/notify()、new ___ 填具体子类、super.___ 照类图方法名抄。
最后有文字题就用万能三句话：「该模式将 X 与 Y 解耦/封装了变化点，新增功能无需修改原有代码，符合开闭原则，提高了系统的可扩展性和可维护性。」——模式名对了+这段话，最后一问的分就到手。
