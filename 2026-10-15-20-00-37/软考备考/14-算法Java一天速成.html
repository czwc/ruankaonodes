上午 · 算法题认空（试题四，必答 15 分，目标 5~8）

先破除恐惧：算法题=一段代码挖了 4~6 个空 + 每空给下拉选项。你不需要看懂整段代码，只需要认出"空长什么样"——空的答案 90% 落在下面五类里。选项是下拉给的（通常 3~5 个），先排除类型对不上的，剩下蒙顺眼的。
考场固定流程（背下来）：① 先读题干文字说明——算法思想一般直接白纸黑字写着，读完你就知道这段代码在干嘛；② 看变量名——sum 是累加、max 是最大、temp 是中转、flag 是标记，名字就是提示；③ 认出一个空填一个空；④ 全填完，不留空。

五类空 · 每类一道迷你例（点开对答案）

例A【循环边界】求数组所有元素的和：
  int sum = 0;
  for (int i = __①__; i < n; i++)      // 从哪开始？
      sum = sum + a[i];
例A 答案
① 填 0。循环从数组第一个元素（下标 0）开始。口诀：数组下标从 0 开始，循环起点几乎都是 i=0。
例B【递归出口】算阶乘 n! = n×(n-1)×…×1：
  int fact(int n) {
      if (n <= 1) return __①__;         // 最小情况的答案
      return n * __②__;                  // 自己调自己
  }
例B 答案
① 填 1（1! = 1，最小输入的直接答案）。② 填 fact(n-1)——递归 = 出口 + "规模缩小一点的自调用"，函数体内唯一一个函数名调用就是它。
例C【累加/最值】求数组最大值：
  int max = a[0];
  for (int i = 1; i < n; i++)
      if (a[i] > max) __①__;            // 发现更大的怎么办？
  return __②__;                          // 最后交出谁？
例C 答案
① 填 max = a[i]（"比 max 大就换上去"）。② 填 max——函数一路在攒谁，最后就返回谁。判断技巧：题干说"求最大值"，代码里叫 max 的变量就是答案。
例D【交换/移动】把两个数换位置：
  if (a[j] > a[j+1]) {
      int t = a[j];
      __①__;                             // 中间步
      a[j+1] = t;
  }
例D 答案
① 填 a[j] = a[j+1]。交换永远是三步曲：t=甲 → 甲=乙 → 乙=t。看到第一行 t=a[j]、第三行 a[j+1]=t，中间只可能是 a[j]=a[j+1]。两个空夹一个 temp 的话，两个空填一样的。
例E【返回值】在数组里找 key，找到了返回下标：
  return __①__;   // 循环里没 return，走到底这行
例E 答案
① 填 -1（"没找到"的行业约定）。规律：循环中找到了 return i（下标）；走到底还没找到，返回 -1 或 -1 类的标记值——题干文字说明里通常会写"若不存在则返回-1"。
五类空速记（就 5 行）：① 循环起点 i=0；② 递归出口=最小答案（1/0/n）；③ 累加 sum+a[i]、最值换 max；④ 交换三步曲夹 temp；⑤ 返回值=一路攒的变量，没找到=-1。

三大高频算法 · 三句话版（只记结论，不学思想）

真题最爱的三种，每种给你"填空专用结论"，看到对应代码直接套：
算法认得出它填空专用结论
二分查找 代码里有 low / high / mid，题干说"有序" ①循环条件 low <= high（带等号）；②a[mid] 比 key 大 → 目标在左 → high = mid-1；比小 → low = mid+1；③没找到 return -1。就这三条，全对可能。
冒泡/选择排序 两层 for 套 if 比较 + 交换 外层 i<n（或 n-1），内层 j<n-1-i（冒泡：每轮冒出一个，所以减 i）；比较后交换 = 三步曲夹 temp；内层比较方向看题干要"升序"还是"降序"（a[j]>a[j+1] = 大的往后 = 升序）。
递归 函数体里出现了自己的名字 只找两样：①出口 if(n<=0/==1) return 最小答案；②规律式 = 题干文字里那条公式（如"f(n)=f(n-1)+f(n-2)"），照着翻译。文字说明=答案，逐字对照。
遇到完全没见过的算法怎么办：也按五类空蒙——循环开头 i=0、递归出口给最小值、交换夹 temp、return 攒变量。5 个空认出 3 个 = 6 分上下，够本了。千万不要试图"看懂整段代码"，那是给已经会的人的奢侈品。

下午 · Java 题认空（试题五 C++ / 试题六 Java 二选一，选 Java）

先破除恐惧：Java 题的真面目是"设计模式连线题"。它考的不是 Java 语法，是"给你一个场景 + 一张类图 + 一段挖空的代码，让你对号入座"。类图上信息齐全，一半的空不用读代码、看图就能填。

第1步 · 认 5 个字（Java 全卷你只需要认识这 5 个词）

词白话
class"类" = 一个模具/工种（如：折扣规则）
interface"接口" = 一份岗位要求清单（只列要会干什么，不写怎么干）
extends"继承" = 我是我爸那种人（类继承类）
implements"实现" = 我签了这份岗位要求（类落实接口）
new"创建" = 招一个具体的人上岗

第2步 · 类图怎么看（30 秒学完）

· 三角实线箭头 → 指向父类（继承，用 extends）
· 三角虚线箭头 → 指向接口（实现，用 implements）
· 菱形箭头 → "整体-部分"（整体那端有菱形）
· 类图框里第一行是类名，中间是属性，下面是方法——方法名照图抄，不会错

第3步 · 完整例题逐空走（策略模式·会员折扣）

题干场景："订单结算时，普通会员原价，VIP 打八折，以后可能新增新会员类型——折扣方式可以随意切换。"第一反应：算法/做法可切换 = 策略模式（这是设计模式题第一空分：先定模式名）。
interface Discount {                       // 一份"折扣岗位要求"
      double calc(double price);            // 要求：会算折后价
  }

  class NormalDiscount __①__ Discount {     // 普通会员签这份要求
      public double calc(double price) { return price; }
  }

  class VipDiscount implements Discount {
      public double calc(double price) { return price * 0.8; }
  }

  class Order {
      private __②__ discount;               // 订单手里握一份"折扣要求"
      public void setDiscount(Discount d) { this.discount = d; }
      public double pay(double price) {
          return discount.__③__(price);     // 让手里的折扣去算
      }
  }

  // 用法：order.setDiscount(new __④__());   // 给 VIP 打折
逐空拆解（每空告诉你"为什么是它"）
空① = implements：Discount 是 interface（岗位要求），类签要求用 implements（类图上是三角虚线指向它）。
空② = Discount：声明"手里握一份什么"，填接口名——类图里 Order 的箭头指向 Discount。
空③ = calc：调用方法名，照接口里抄——接口里只定义了 calc，选项里别的都是干扰。
空④ = VipDiscount：new = 招具体的人，场景说"VIP 打八折"，new 后面填具体子类名。
看出来了吗？4 个空没有一个需要"懂 Java"，全靠认字 + 看类图 + 抄方法名。
Java 五类空位（背这一段就够了）：① class A ___ B → B 是接口填 implements、是类填 extends；② 声明变量的类型 ___ → 填接口名；③ new ___() → 填具体子类名；④ 调方法 ___() → 照类图/接口抄方法名；⑤ super.___ / this.___ → 父子同名，抄同一个。

六大高频模式 · 特征词表（先背特征词，题干一出现就能定模式）

模式题干特征句代码/类图特征（挖空爱考的）
观察者"状态变化时自动通知所有依赖者"notify() / update()；遍历列表逐个调用
策略"算法/做法可以切换"统一接口 + 多个实现类；成员变量是接口类型
单例"全局只能有一个实例"getInstance()；private 构造函数；static 自己 new 自己
工厂方法"创建什么由子类决定"createXxx() 返回接口类型；new 的活交给子类
装饰器"不加子类动态加功能"构造函数传入同类型对象（包一层）；方法里前后加料
代理"中转/控制对目标的访问"和目标同接口；方法里"先…再调真身…再…"，出现 realSubject
最后一问万能模板（"这里用了什么模式，为什么"）："采用了 ××模式。因为题干场景符合'特征句'（抄题干原话+本表第二列），类图中 抽象/接口类 与 具体类 的关系也与之对应。"——三句话，即使不确定也能拿步骤分。

自测 6 题（全对 = 明天这两题你就有底了）

① 二分查找：while (low ___ high) 填什么？
<=（带等号——区间剩 1 个元素时还要查一次）。
② 二分查找：a[mid] > key 时，high = ___？
mid-1（中间值比目标大 → 目标在左半边 → 右边界左移）。
③ 递归算 n!，出口 if(n<=1) return ___？
1（1! = 1，最小输入的直接答案）。
④ class Cat ___ Animal，Animal 是类不是接口，填什么？
extends（类继承类；接口才用 implements——类图三角实线 vs 虚线）。
⑤ 题干"天气一变，所有公告板自动刷新"，这是什么模式？核心方法名？
观察者模式；核心方法 notify() / update()（遍历列表逐个调用）。
⑥ order.setDiscount(new ___())，场景是"VIP 打八折"，填什么？
VipDiscount（new 后面跟具体子类名，类图继承箭头末端的那个）。
