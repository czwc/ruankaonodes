小白词典（黑话翻译成大白话）：
· 程序图的节点/边：流程图里圆圈=节点，箭头=边；McCabe 就是"数箭头−数圆圈+2"。
· 尾数/阶码：浮点数就是二进制版科学计数法。3.14×10² 里 3.14 是尾数（管精度，几位有效数字），2 是阶码（管范围，数有多大）。
· Cache/命中率：Cache 是 CPU 旁边的小而快的内存；命中率=要的数据正好在里面、不用去慢内存找的比例。
· 原码/反码/补码：电脑存正负数的三种写法；只记"正数三码相同，负数补码=反码+1"。
· 内部碎片/外部碎片：内部=分给你的块没用完，浪费在块里面；外部=剩下的空隙太小、凑不成整块，浪费在块外面。
· S 锁/X 锁：S=读锁，可以很多人同时读；X=写锁，一个人写、其他全部等着。
· 入度：指向这个点的箭头条数。"入度为 0"=没有箭头指向它，可以最先输出。
· WPL：哈夫曼树的总代价 = 每个叶子的（数值 × 离根的层数）再全部加起来，越小越好。
· 前缀码：任何一个编码都不是另一个的开头，所以连着写也不会读错（如 A=0、B=10，"010"=A B A 不歧义）。
· 子网掩码 /24：掩码里二进制 1 的个数；/24 = 前 24 位是网络号，剩 8 位给主机。
· 总时差：最晚开始 − 最早开始；=0 表示这个活动一天都不能拖（在关键路径上）。
· 候选码/闭包：候选码=能唯一认出一条记录的最小属性组合；闭包=由某属性出发能推出哪些其他属性（手算四步法见 Day2 规范化框）。

▶ 测试（每年 2~3 题）

黑盒（功能）：等价类划分、边界值分析、因果图、错误推测。
白盒（结构）：逻辑覆盖由弱到强：语句 → 判定 → 条件 → 判定/条件 → 条件组合 → 路径覆盖。
McCabe 环形复杂度：V(G) = 边数 − 节点数 + 2（或 = 判定节点数 + 1）。白盒测试用例数 ≥ V(G)。
阶段划分：单元测试（程序员自测/白盒）→ 集成（接口）→ 确认（需求/用户）→ 系统 → 验收（α测试=开发方场所用户测，β=用户场所）。

▶ 耦合与内聚（必考排序）

耦合低→高（越好越靠前）：数据 < 标记 < 控制 < 外部 < 公共 < 内容
口诀"数标控外公内"逐字拆：数=数据耦合（只传简单数值，最好）→ 标=标记（传结构/记录）→ 控=控制（传开关指令操纵别人）→ 外=外部（共享软件环境）→ 公=公共（共享全局数据）→ 内=内容（直接进别人内部改数据，最差）。
内聚高→低（越好越靠前）：功能 > 顺序 > 通信 > 过程 > 时间 > 逻辑 > 偶然
口诀"功顺通过时逻偶"逐字拆：功=功能（一件事干到底，最好）→ 顺=顺序（上一步输出是下一步输入）→ 通=通信（围绕同一数据集干活）→ 过=过程（按固定流程走）→ 时=时间（同一时间段凑一起，如初始化）→ 逻=逻辑（一堆功能靠参数挑着执行）→ 偶=偶然（毫无关系凑一起，最差）。
考试判断口诀：看到"直接改内部数据"选内容（最差）；看到"只传一个数值"选数据（最好）；看到"参数决定执行哪个功能"选逻辑内聚。

▶ 项目管理 + CMM + 质量（每年 2~3 题）

关键路径：项目中最长的路径，决定总工期；关键路径上活动总时差为 0。总时差 = 最迟开始 − 最早开始。
甘特图：直观显示进度，但难以反映任务间依赖；PERT 图/箭线图能反映依赖。
CMM 五级：初始（混乱）→ 可重复（项目级管理）→ 已定义（组织级标准过程）→ 已管理（定量管理）→ 优化（持续改进）；CMMI = CMM 升级版，有阶段式（五级同上）和连续式两种表示。
McCall 质量特性：功能性、可靠性、易使用性、效率、维护性、可移植性。

▶ 需求 / 维护 / 风险（每年 2~3 题）

需求分类：功能需求（做什么）/ 非功能需求（性能、安全性等约束）/ 设计约束；需求开发 = 获取 → 分析 → 定义（写规格说明书）→ 确认；需求管理 = 变更控制 + 需求跟踪。
软件维护四类：改正性（修 bug）、适应性（环境变了）、完善性（加功能，占比最大约 50%）、预防性（防患未然）——考"占比最大"答完善性。
风险管理流程：风险识别 → 风险预测/评估 → 风险控制；风险暴露 = 风险损失 × 概率。

▶ 面向对象概念 + 七大原则（每年 2~3 题）

三大特征：封装（隐藏实现）、继承（复用）、多态（同一消息不同对象不同响应，重载=编译时绑定、重写=运行时绑定）。
类与对象：类是对象的抽象模板，对象是类的实例；接口 = 只含抽象方法规范。
七大原则一句话：单一职责（一个类只干一件事）、开闭（对扩展开放对修改关闭，最重要）、里氏替换（子类能替换父类）、依赖倒置（面向接口编程）、接口隔离（接口要小而专）、迪米特（最少知识，只和直接朋友通信）、组合复用（优先组合而非继承）。

▶ SQL 高频句式（每年 2~3 题）

标准查询：SELECT 列 FROM 表 WHERE 条件 GROUP BY 分组列 HAVING 组条件 ORDER BY 排序列——顺序固定：WHERE 在 GROUP 前，HAVING 在 GROUP 后（HAVING 配聚合函数）。
授权：GRANT SELECT,INSERT ON 表 TO 用户 WITH GRANT OPTION（可转授）；回收 REVOKE。
视图：CREATE VIEW 视图名 AS SELECT ...——视图是虚表，提高安全性/逻辑独立性。
属性函数：COUNT/SUM/AVG/MAX/MIN；DISTINCT 去重。

▶ 规范化 + 候选码四步法（每年 2~3 题）

候选码四步法（手算模板）：① 分类——把函数依赖看箭头：只出现在左边的属性（决定别人）必在候选码里，只在右边的（被决定）一定不在；② 从"只左边 + 两边都出现"的属性出发求闭包（能推出谁就加进集合）；③ 闭包 = 全部属性 → 得到一个候选码；④ 有多组就逐组试，得到全部候选码，选一个当主键；在候选码里的叫主属性，其余叫非主属性——这是判断范式的分界线。
判断范式口诀"一化要原子，二化消部分，三化消传递，BC 看左部"逐字拆：一化=每个字段不可再拆；二化=非主属性不能只依赖主键的一部分（针对联合主键）；三化=非主属性之间不能互相依赖（A→B→主键这种传递链要拆开）；BCNF=每个决定因素都必须是候选码（比三化更严）。
关系代数送分：σ（选择/行）π（投影/列）⋈（连接）——注意"投影后同列去重"。
E-R 转关系模式：每个实体一个模式；1:1 和 1:n 联系并入对方模式（加上对方主键）；m:n 联系必须单独建表，主键 = 两端主键组合。

▶ 例9【范式判定】真题标准套路（先自己判 2 分钟，再对步骤）

已知 R(A,B,C,D)，函数依赖 F = {A→B, B→C, A→D}。求候选码？R 最高满足第几范式？
第一步：求候选码（四步法）。看箭头谁只在左边：B、C、D 都被别人决定过，只有 A 从不做"右边"→ A 必在候选码。求 A 的闭包：A → 得 B（A→B）→ 得 C（B→C）→ 得 D（A→D），A⁺ = {A,B,C,D} = 全部属性 → 候选码就是 A（只有一个）。
第二步：分主次。主属性 = A；非主属性 = B、C、D。（范式判断只看非主属性对候选码的依赖）
第三步：按顺序检查坏依赖。
· 判 2NF：非主属性有没有"只依赖候选码一部分"？候选码 A 是单属性，不存在部分依赖 → 满足 2NF ✓
· 判 3NF：有没有传递依赖？发现 A→B→C：C 不直接依赖 A，而是通过 B 传递过来 → 存在传递依赖，不满足 3NF ✗
结论：R 最高满足 2NF。
第四步（若问"分解成 3NF"）：把传递链拆开——R1(A,B,D) + R2(B,C)，两表内都不再有传递依赖 → 都达 3NF。
易错：①判 2NF 的前提是候选码为多属性才有"部分依赖"可谈，单属性候选码自动满足 2NF；②"B→C 且 A→B"就叫传递依赖，别因为 A 也直接→D 就忽略 C；③问"最高满足第几范式"= 从 2NF 往上逐级查，碰到第一个不满足的就停。

▶ PV 操作（每年 1~2 题，模板固定）

互斥：一个信号量初值 = 1；进临界区 P，出临界区 V。
同步（生产者-消费者）：empty 初值 = 缓冲区大小 n；full 初值 = 0；mutex 初值 = 1。
生产者：P(empty) → P(mutex) → 放产品 → V(mutex) → V(full)；消费者：P(full) → P(mutex) → 取产品 → V(mutex) → V(empty)。
口诀：同步在前，互斥在后（两个 P 的顺序不能颠倒，否则死锁）。
为什么顺序不能反？若先 P(mutex) 再 P(empty)：缓冲区满时生产者拿着 mutex 却等不到 empty，消费者想取产品又进不了 mutex → 互相等死。
例10【PV 填空】真题套路：生产者-消费者，缓冲区容量 n，把 P/V 填进空格
生产者：P(empty) → P(mutex) → 放产品 → V(mutex) → V(full)
消费者：P(full) → P(mutex) → 取产品 → V(mutex) → V(empty)
填空技巧：①看到"申请空缓冲"→ P(empty)；"申请产品"→ P(full)；②进临界区前 P(mutex)、出来立刻 V(mutex)——mutex 的 P/V 永远成对夹住操作；③信号量命名规律：资源名（empty/full）管同步、mutex 管互斥；④选项里若有"P(mutex) 在 P(empty) 之前"就是错误答案（顺序反了会死锁）。
变体：两个生产者共享 m 个缓冲 → empty 初值 m；一次放 k 个 → 申请 k 个空位（P(empty) k 次）。

▶ 四个必背公式（每年 3~4 题）

① 浮点数：N = 尾数 × 2^阶码。范围由阶码位数决定，精度由尾数位数决定（选择常考这两句的对调）。规格化：尾数最高位为 1。
② 可靠性：串联 R = R1 × R2 × …；并联 R = 1 − (1−R1)(1−R2)；串联可靠性随部件增多降低，并联提高。
③ Cache：平均访问时间 = 命中率 × Cache 时间 + (1−命中率) × 主存时间（顺序访问式）或 + (1−命中率) × (Cache+主存) 时间（同时访问式）——看清题干给哪种。
④ 流水线：总时间 = 1 条完整指令时间 + (n−1) × 流水线周期（周期 = 最长段耗时）；吞吐率 = n ÷ 总时间；加速比 = 不用流水时间 ÷ 流水时间。
⑤ I/O 方式：程序查询（CPU 轮询干等，最慢）→ 中断（设备就绪才打断 CPU）→ DMA（数据直接进内存，基本不占 CPU，块设备主流方式）。
⑥ CPU 组成：运算器（ALU、累加器、状态寄存器）+ 控制器（PC 程序计数器、IR 指令寄存器、译码器）。
⑦ 流水线三种相关：资源相关、数据相关（后条要用前条结果）、控制相关（转移指令）——解决靠停顿/重排。

▶ 四大公式·真题级例题（先自己算 1 分钟，再点开对步骤）

例1【流水线】四段流水线各段耗时 1/2/3/4ns，执行 100 条指令总时间？加速比？
周期 = 最长段 = 4ns。总时间 = (1+2+3+4) + (100−1)×4 = 10 + 396 = 406ns。
加速比 = 不流水时间 ÷ 流水时间 = (100×10) ÷ 406 ≈ 2.46。
丢分点：首条指令时间 = 各段之和，别用周期代替。
例2【Cache】命中率 90%，Cache 40ns，主存 200ns，平均访问时间？
顺序访问式：T = 0.9×40 + 0.1×200 = 36 + 20 = 56ns。
丢分点：若题干说"同时访问"，第二项要写成 0.1×(40+200)=24，T=60ns——看清题干！
例3【可靠性】两个子系统串联，每个子系统由 2 个可靠度 0.9 的部件并联，系统可靠度？
先并联：R = 1 − (1−0.9)² = 1 − 0.01 = 0.99；
再串联：R = 0.99 × 0.99 = 0.9801。
口诀：先小后大——先把每个子系统算成一个数，再串。
例4【子网】200.1.1.0/27 划分，每个子网可用主机数？能分几个子网（相对 /24）？
/27 → 主机位 = 32−27 = 5 位 → 可用主机 = 2⁵−2 = 30 台；
网络位比 /24 多 3 位 → 子网数 = 2³ = 8 个。
计算题分值地图（每年约 10 分，全在这页里）：流水线/Cache/可靠性（3~4 分，见上面例 1~3）+ 子网划分（1 分，例 4）+ 页式地址转换/磁盘/位示图（2~3 分，见下面例 5~7）+ 多媒体容量（1 分，例 8）+ 零散小计算（海明 k 值、循环队列、二分次数、EMV——都在各 Day 的 30 秒自测里）。计算题是"套模板"不是"想思路"：认出题型 → 代对应模板 → 每步一个动作。

▶ 更多必考计算·照步骤一步步套（先自己算再对答案）

例5【页式地址转换】页大小 1KB，逻辑地址 2500，该页装入内存帧号 4，物理地址 = ？
三步：① 求页内偏移位数：1KB=2¹⁰ → 低 10 位是偏移；② 拆逻辑地址：页号 = 2500 ÷ 1024 = 2（整除），偏移 = 2500 − 2×1024 = 452；③ 物理地址 = 帧号 × 页大小 + 偏移 = 4×1024 + 452 = 4548。
易错：页大小换成 4KB 就用 4096 除；"页号查表得帧号"这步题干会给映射表，别拿页号当帧号用。
例6【磁盘存取】转速 6000 转/分，平均寻道 4ms，每磁道 50 扇区，读 1 个扇区总时间 = ？
先懂原理再套数：磁头读数据 = 先把臂移到对的磁道（寻道）→ 等盘转到目标扇区转到磁头下面（旋转延迟）→ 扇区从磁头下扫过（传输）。三段相加就是总时间。
三步：① 转一圈 = 60 秒 ÷ 6000 转 = 0.01 秒 = 10ms；② 为什么平均旋转延迟是半圈？——磁头不知道目标扇区此刻在哪，运气最好立刻到、最差要等一整圈，平均就是一半 = 5ms；③ 传输 = 读一个扇区 = 一圈的 1/50 = 10 ÷ 50 = 0.2ms。
总时间 = 4 + 5 + 0.2 = 9.2ms。
易错：①"转/分"要先换成每圈毫秒（60000 ÷ 转速）；②若问"读一整个磁道"，传输 = 一整圈 10ms，不用除 50。
例7【位示图】字长 32 位，块号 100（从 0 编号），它在第几个字、第几位？
字号 = 100 ÷ 32 = 3 余 4 → 第 3 个字（从 0 数）、位号 4；若题干说"从 1 开始编号"则答案是第 4 个字、第 5 位。
易错：唯一坑就是"从 0 还是从 1 编号"——题干读两遍再填。
例8【图像容量】800×600 像素、16 色图像，占多少 KB？
两步：① 16 色 = 2⁴ → 每像素 4 位；② 容量 = 800 × 600 × 4 ÷ 8 = 240000B ÷ 1024 ≈ 234KB。
易错："16 色"是 4 位不是 16 位（16 位=65536 色）；音频题则用 采样率×量化位×声道×秒 ÷ 8。

▶ 寻址方式 + 校验码 + RAID（每年 2~3 题）

寻址速度：立即 > 寄存器 > 直接 > 间接（立即最快不用访存；间接访存两次最慢，但寻址范围最大）。
校验码：奇偶校验——只能检 1 位错，不能纠错；CRC 循环冗余——只能检错不能纠错（模 2 除法）；海明码——能纠 1 位错，公式 2^k ≥ n + k + 1（n 数据位、k 校验位）。
RAID：RAID0 条带无冗余（快但坏一块全丢）；RAID1 镜像（利用率 50%）；RAID5 分布式奇偶校验（坏一块可恢复，n 块盘可用 n−1）。
码制：正数原码=反码=补码；负数补码 = 反码 + 1；补码的 0 表示唯一（原码有两个 0）；移码常用于表示浮点数的阶码。
Flynn 分类：按"指令流×数据流"分四种——SIMD（单指令多数据：阵列/向量处理器）、MIMD（多指令多数据：多核/多处理机）；SISD 单处理机。
CISC vs RISC：RISC = 指令少、定长、寻址方式少、寄存器多、流水线友好；CISC = 指令复杂变长（x86 是 CISC）。

▶ 网络基础（每年 3~5 题）

OSI 七层：物理、数据链路、网络、传输、会话、表示、应用。口诀"巫师忘传会赢死"逐字拆：巫=物理层、师=数据链路层、忘=网络层、传=传输层、会=会话层、赢=表示层、死=应用层（从下往上背）。
协议对号：应用层 HTTP/FTP/SMTP/DNS/DHCP；传输层 TCP（面向连接、可靠、三次握手）/ UDP（无连接、不可靠、快）；网络层 IP/ICMP/ARP；传输介质以下物理层。
子网划分：子网掩码 1 的个数 = 网络位；可用主机数 = 2^主机位 − 2（去掉网络地址和广播地址）。/26 → 主机位 6 → 62 台；/28 → 14 台。
常用：C 类默认掩码 255.255.255.0（/24），网关是"通往其他网络的出口 IP"；IPv6 地址长度 128 位。
端口：FTP 20/21、SSH 22、Telnet 23、SMTP 25、DNS 53、HTTP 80、HTTPS 443、POP3 110。
IP 分类：A 类 1~126、B 类 128~191、C 类 192~223；127.0.0.1 本机回环；255.255.255.255 受限广播；169.254.x.x 自动专用（没拿到 DHCP）。
协议用途一句话：DNS=域名转 IP；DHCP=自动分配 IP；SMTP=发邮件；POP3=收邮件；ARP=IP 转 MAC 地址。
设备对号（常考！）：中继器/集线器 → 物理层；网桥/交换机 → 数据链路层；路由器 → 网络层；网关 → 高层（应用层）。
CSMA/CD：共享式以太网的介质访问控制——先听后发、边发边听、冲突停发。

▶ 信息安全（每年 3~4 题，纯背）

对称加密：加解密同一把密钥，速度快，适合大数据——DES、3DES、AES、RC4；缺点：密钥分发难。
非对称加密：公钥加密、私钥解密（公钥可公开），慢，适合小数据——RSA、ECC、DSA。
混合加密：用非对称加密传对称密钥，再用对称加密传数据（HTTPS 的思路）。
信息摘要（MD5/SHA）：保证完整性防篡改；数字签名 = 发送方用自己私钥签名，接收方用对方公钥验证——完整性 + 防抵赖（本身不加密）。
数字证书：CA 颁发，把公钥和身份绑定，防"假冒公钥"。
防火墙：部署在内网与外网之间，按规则过滤；IDS 只检测报警、IPS 能阻断；病毒=寄生传播，木马=后门被控，蠕虫=独立自我复制。
常见攻击：DoS/DDoS 拒绝服务（打瘫服务）、SQL 注入（输入恶意 SQL 骗数据库）、XSS 跨站脚本（注入恶意网页脚本）、钓鱼=仿冒网站骗账号。
密钥管理：会话密钥（对称）常用 KDC 集中分发；公钥真伪靠数字证书/CA 验证。

▶ 排序算法表（每年 2~3 题，必背）

算法平均最坏稳定性
插入 / 冒泡O(n²)O(n²)稳定
选择O(n²)O(n²)不稳定
希尔≈O(n^1.3)O(n²)不稳定
快速O(n log n)O(n²)（基本有序时最差）不稳定
归并O(n log n)O(n log n)稳定
堆排O(n log n)O(n log n)不稳定
稳定性口诀："快些选堆"不稳定（快速、希尔、选择、堆）。其余（插入/冒泡/归并/基数）稳定。
例11【排序一趟】真题套路：序列 45,23,12,9，各种排序"第一趟"后各是什么？
关键是每种的"一趟"含义不同：
· 冒泡：从头两两比较，逆序就换 → 最大数 45 沉底 → 23,12,9,45
· 插入：把第 2 个元素 23 插到前面有序区 → 23,45,12,9（只有前两个有序）
· 选择：从头到尾找最小值 9，与第 1 个位置交换 → 9,23,12,45
· 快排（以 45 为枢轴）：比 45 小的都挪左边，45 落到最终位置 → 9,23,12,45
做题技巧：①冒泡/选择一趟后必有 1 个元素就最终位；②插入一趟后只有前 2 个元素有序；③快排一趟后枢轴必在最终位——用这三条反推选项。
易错：希尔排序的一趟是"按增量分组各排"，和上面完全不同，看到希尔直接回忆"分组插入"。

▶ 数据结构高频点

二叉树：叶子数 n0 = n2 + 1（n1 为度 1 节点）；n 个节点的完全二叉树高度 = ⌈log₂(n+1)⌉；前序+中序可唯一重建二叉树（前+后不行）。
三种遍历口诀：都是"根的时机"不同——前序=根左右、中序=左根右、后序=左右根（先中后说的是根的位置）。
图：DFS 用栈，BFS 用队列；n 顶点邻接矩阵存储空间 O(n²)。
复杂度链：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)（教程 04 篇）。
栈与队列：栈先进后出（递归、表达式求值用栈）、队列先进先出；循环队列元素个数 = (rear − front + 容量) mod 容量。
查找：二分查找最多比较 ⌈log₂(n+1)⌉ 次，前提顺序存储 + 有序；散列（哈希）按关键码直接定位，冲突处理：线性探测、链地址法；装填因子 = 元素数 ÷ 表长（越大越易冲突）。
哈夫曼树：WPL（带权路径长度）最小的二叉树，没有度为 1 的节点；n 个叶子 → 共 2n−1 个节点；哈夫曼编码是前缀码（不会歧义）。
对称矩阵压缩：只存下三角（含对角线），共 n(n+1)/2 个元素；数组下标（行优先）a(i,j) 地址 = 前 i−1 行元素个数 + j 偏移。
程序语言一句话：编译=先整体翻译成目标程序再执行（报错在编译期）；解释=逐句翻译边执行、不生成目标程序；传值调用形参变化不影响实参，传地址/引用会改变实参。
编译六阶段：词法分析（拆单词）→ 语法分析（句子结构）→ 语义分析（含义检查）→ 中间代码 → 优化 → 目标代码；语法错误编译期报，逻辑错误编译器查不出。
例12【遍历重建】真题套路：前序 ABDECF、中序 DBEAFC，求后序
核心原理：前序第一个永远是根，拿根去中序里切两半。
① 前序首 = A = 根；去中序 DBEAFC 里找 A → 左半 DBE、右半 FC；
② 左子树：前序 BDE + 中序 DBE → 根 = B，中序左 D 右 E → B 的左孩子 D、右孩子 E；
③ 右子树：前序 CF + 中序 FC → 根 = C，中序里 F 在 C 左边 → F 是 C 的左孩子；
④ 树画出来：A(B(D,E), C(F))。后序 = 左右根：DEBFCA。
易错：每层都要"回前序找根、回中序切左右"，别一口气瞎猜；考试一般 3~5 个节点，两步就出答案。

考前必读 · 政策 + 机考 + 考前一晚流程

成绩规则（决定你的战略）：上午、下午两卷必须同次考试都 ≥45 分才算通过，单科过线不作保留——所以：①上午考完感觉砸了，下午照样全力打（上午成绩不由你控制，下午的每一分都由你控制）；②反过来下午难也别提前弃卷，上午分是能救的。
机考要点（软件设计师已全面机考）：
① 上午 75 道单选在屏幕上作答，可标记跳过、系统倒计时——技巧不变：先易后难；
② 下午图表题（数据流图/UML）多为拖拽或下拉选词补全图中的元素 + 文字简答，不是手画图——按空给分，空着必 0 分，不确定也要选一个；
③ 考前一周去官方"模拟作答系统"练 30 分钟（官网免费开放）——熟悉切换题号、标记、拖拽操作，考场不为操作浪费一分钟；
④ 草稿纸照常提供，四公式/口诀/表格默写照用；答案记得随手保存/进入下一题前确认提交。
考前一晚清单（按顺序过一遍）：
① 点本页"回看模式"，只看亮着的板块（你的错题集），看不进的直接放弃；
② 准备：身份证 + 准考证（打印 2 份分开放）、普通手表看时间；
③ 草稿纸上默写一遍：四公式 + "数标控外公内/功顺通过时逻偶" + PV 三信号量 + 排序"快些选堆"；
④ 不背任何新内容——新内容只会挤掉你已记住的，还会让你失眠；
⑤ 睡够 7 小时：睡眠是记忆固化的过程，熬夜一夜 ≈ 报废前三天。
考试当天流程：两卷同一天考。提前 60 分钟到场；开考前默写四公式；上午 150 分钟做完检查"不正确的是"类题；中午别对上午答案（考完一科扔一科，下午的心流最值钱）；下午先通读 5 道大题再动笔。

考场实战技巧（上午 + 下午）

【上午】① 75 题必须全部做完：单选 75 题 ×1 分，及格 45 分。空白 = 白丢分；不会的按"同一字母连蒙"（期望 ≥18 分）。
② 时间分配：上午 150 分钟，75 题平均 2 分钟/题。计算题卡住超过 3 分钟立即标记跳过。
③ 先做记忆题（软件工程/知识产权/英语/模式），再做计算题（页式/磁盘/流水线/子网），最后回头补标记题。
④ 计算题四件套（Day3 的公式）在草稿纸上开考前默写一遍——开考前有几分钟，公式遗忘是最大丢分源。
⑤ 注意"不正确的是"——上午题最阴的陷阱，圈出"不"字再答题。
【下午】① 先通读全部 5 道题再动笔，按把握度排序做（一般：数据库 → 数据流图 → UML → 算法 → Java）；
② 评分按点给分：不确定也要把术语写全（如"此处为 include 关系，因为…是必选复用"），空白必 0 分，写了就有机会；
③ 图题先数个数再画：实体几个、联系几个、消息几条——画完用题干逐句回验，每句描述都应对应图上一个元素；
④ 算法题 15 分钟没思路就先放：先把前 3 道大题拿满，回头攻填空（填空按空给分，蒙边界值也有得分机会）；
⑤ 下午 150 分钟 5 道大题，每道约 28 分钟，超时立即跳下一道——下午的敌人不是难度，是时间。
