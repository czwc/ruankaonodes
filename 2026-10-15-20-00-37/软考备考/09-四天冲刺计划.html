Day 1 · 软件工程 + 面向对象概念日（2h 背 + 1.5h 刷题）

▶ 开发模型（每年 1~2 题）

模型一句话特征（背）适用
瀑布线性顺序、文档驱动、阶段评审后才能进入下一阶段需求明确且稳定
原型快速构造可运行原型，用户确认后再开发需求不明确、模糊
增量分批次交付，核心功能先行，每个增量都可运行需要尽早提供部分产品
螺旋风险驱动，每圈含"计划→风险分析→实施→评估"大型复杂、高风险项目
敏捷小步快跑、拥抱变化、每日站会、结对编程需求多变、小团队

▶ 测试（每年 2~3 题）

黑盒（功能）：等价类划分、边界值分析、因果图、错误推测。
白盒（结构）：逻辑覆盖由弱到强：语句 → 判定 → 条件 → 判定/条件 → 条件组合 → 路径覆盖。
McCabe 环形复杂度：V(G) = 边数 − 节点数 + 2（或 = 判定节点数 + 1）。白盒测试用例数 ≥ V(G)。
阶段划分：单元测试（程序员自测/白盒）→ 集成（接口）→ 确认（需求/用户）→ 系统 → 验收（α测试=开发方场所用户测，β=用户场所）。

▶ 耦合与内聚（必考排序）

耦合低→高（越好越靠前）：数据 < 标记 < 控制 < 外部 < 公共 < 内容
记："数标控，外公内"——内容耦合最差（直接改别人内部数据）。
内聚高→低（越好越靠前）：功能 > 顺序 > 通信 > 过程 > 时间 > 逻辑 > 偶然
记："功顺通过时逻偶"——偶然内聚最差（凑一起没联系）。

▶ 项目管理 + CMM + 质量（每年 2~3 题）

关键路径：项目中最长的路径，决定总工期；关键路径上活动总时差为 0。总时差 = 最迟开始 − 最早开始。
甘特图：直观显示进度，但难以反映任务间依赖；PERT 图/箭线图能反映依赖。
CMM 五级：初始（混乱）→ 可重复（项目级管理）→ 已定义（组织级标准过程）→ 已管理（定量管理）→ 优化（持续改进）。
McCall 质量特性：功能性、可靠性、易使用性、效率、维护性、可移植性。

▶ 需求 / 维护 / 风险（每年 2~3 题）

需求分类：功能需求（做什么）/ 非功能需求（性能、安全性等约束）/ 设计约束；需求开发 = 获取 → 分析 → 定义（写规格说明书）→ 确认；需求管理 = 变更控制 + 需求跟踪。
软件维护四类：改正性（修 bug）、适应性（环境变了）、完善性（加功能，占比最大约 50%）、预防性（防患未然）——考"占比最大"答完善性。
风险管理流程：风险识别 → 风险预测/评估 → 风险控制；风险暴露 = 风险损失 × 概率。

▶ 面向对象概念 + 七大原则（每年 2~3 题）

三大特征：封装（隐藏实现）、继承（复用）、多态（同一消息不同对象不同响应，重载=编译时绑定、重写=运行时绑定）。
类与对象：类是对象的抽象模板，对象是类的实例；接口 = 只含抽象方法规范。
七大原则一句话：单一职责（一个类只干一件事）、开闭（对扩展开放对修改关闭，最重要）、里氏替换（子类能替换父类）、依赖倒置（面向接口编程）、接口隔离（接口要小而专）、迪米特（最少知识，只和直接朋友通信）、组合复用（优先组合而非继承）。

Day 2 · 数据库 + 操作系统日

▶ SQL 高频句式（每年 2~3 题）

标准查询：SELECT 列 FROM 表 WHERE 条件 GROUP BY 分组列 HAVING 组条件 ORDER BY 排序列——顺序固定：WHERE 在 GROUP 前，HAVING 在 GROUP 后（HAVING 配聚合函数）。
授权：GRANT SELECT,INSERT ON 表 TO 用户 WITH GRANT OPTION（可转授）；回收 REVOKE。
视图：CREATE VIEW 视图名 AS SELECT ...——视图是虚表，提高安全性/逻辑独立性。
属性函数：COUNT/SUM/AVG/MAX/MIN；DISTINCT 去重。

▶ 规范化（你教程 00 篇 ⑦⑧ 节现成，30 分钟复习）

四步：分类求闭包 → 找候选码 → 找主/非主属性 → 查坏依赖。口诀"一化要原子，二化消部分，三化消传递，BC 看左部"。
关系代数送分：σ（选择/行）π（投影/列）⋈（连接）——注意"投影后同列去重"。

▶ PV 操作（每年 1~2 题，模板固定）

互斥：一个信号量初值 = 1；进临界区 P，出临界区 V。
同步（生产者-消费者）：empty 初值 = 缓冲区大小 n；full 初值 = 0；mutex 初值 = 1。
生产者：P(empty) → P(mutex) → 放产品 → V(mutex) → V(full)；消费者：P(full) → P(mutex) → 取产品 → V(mutex) → V(empty)。
口诀：同步在前，互斥在后（两个 P 的顺序不能颠倒，否则死锁）。

▶ 进程状态 + 死锁

三态转换：就绪→运行（被调度）；运行→就绪（时间片到）；运行→阻塞（等资源）；阻塞→就绪（资源到位）。阻塞不能直接到运行，运行不能直接到阻塞的逆——选择题爱画 6 条箭头让你判断哪条不存在。
死锁四条件：互斥、请求保持、不剥夺、环路等待（破坏任一条可预防；银行家算法是"避免"死锁）。

▶ 事务 + 并发控制 + 文件管理（每年 2~3 题）

事务 ACID：原子性（全做或全不做）、一致性（一致态到一致态）、隔离性（并发互不干扰）、持续性（提交后永久生效）。
并发三类问题：丢失修改、读脏数据、不可重复读；解决 = 封锁协议：S 锁（读锁）可共享、X 锁（写锁）独占；两段锁协议保证可串行化。
位示图：字号 = ⌈块号 ÷ 字长⌉，位号 = 块号 mod 字长（看清从 0 还是 1 编号）。
磁盘调度：FCFS 先来先服务；SSTF 找最近请求（可能饿死远端）；SCAN 电梯算法沿一个方向扫到头再折返。

▶ 页式存储 / 磁盘（教程 00 篇现成）

复习 00 上午题教程：地址转换三步法、FIFO/LRU/OPT 缺页、磁盘存取时间 = 寻道 + 旋转延迟 + 传输、位示图（字号 = 块号 ÷ 字长，位号 = 余数）。

Day 3 · 硬件 + 网络 + 安全 + 知识产权 + 英语（送分大日）

▶ 四个必背公式（每年 3~4 题）

① 浮点数：N = 尾数 × 2^阶码。范围由阶码位数决定，精度由尾数位数决定（选择常考这两句的对调）。规格化：尾数最高位为 1。
② 可靠性：串联 R = R1 × R2 × …；并联 R = 1 − (1−R1)(1−R2)；串联可靠性随部件增多降低，并联提高。
③ Cache：平均访问时间 = 命中率 × Cache 时间 + (1−命中率) × 主存时间（顺序访问式）或 + (1−命中率) × (Cache+主存) 时间（同时访问式）——看清题干给哪种。
④ 流水线：总时间 = 1 条完整指令时间 + (n−1) × 流水线周期（周期 = 最长段耗时）；吞吐率 = n ÷ 总时间；加速比 = 不用流水时间 ÷ 流水时间。

▶ 寻址方式 + 校验码 + RAID（每年 2~3 题）

寻址速度：立即 > 寄存器 > 直接 > 间接（立即最快不用访存；间接访存两次最慢，但寻址范围最大）。
校验码：奇偶校验——只能检 1 位错，不能纠错；CRC 循环冗余——只能检错不能纠错（模 2 除法）；海明码——能纠 1 位错，公式 2^k ≥ n + k + 1（n 数据位、k 校验位）。
RAID：RAID0 条带无冗余（快但坏一块全丢）；RAID1 镜像（利用率 50%）；RAID5 分布式奇偶校验（坏一块可恢复，n 块盘可用 n−1）。

▶ 网络基础（每年 3~5 题）

OSI 七层：物理、数据链路、网络、传输、会话、表示、应用。口诀"巫师忘传会赢死"（物数网传会表应）。
协议对号：应用层 HTTP/FTP/SMTP/DNS/DHCP；传输层 TCP（面向连接、可靠、三次握手）/ UDP（无连接、不可靠、快）；网络层 IP/ICMP/ARP；传输介质以下物理层。
子网划分：子网掩码 1 的个数 = 网络位；可用主机数 = 2^主机位 − 2（去掉网络地址和广播地址）。/26 → 主机位 6 → 62 台；/28 → 14 台。
常用：C 类默认掩码 255.255.255.0（/24），网关是"通往其他网络的出口 IP"；IPv6 地址长度 128 位。
端口：FTP 20/21、SSH 22、Telnet 23、SMTP 25、DNS 53、HTTP 80、HTTPS 443。

▶ 信息安全（每年 3~4 题，纯背）

对称加密：加解密同一把密钥，速度快，适合大数据——DES、3DES、AES、RC4；缺点：密钥分发难。
非对称加密：公钥加密、私钥解密（公钥可公开），慢，适合小数据——RSA、ECC、DSA。
混合加密：用非对称加密传对称密钥，再用对称加密传数据（HTTPS 的思路）。
信息摘要（MD5/SHA）：保证完整性防篡改；数字签名 = 发送方用自己私钥签名，接收方用对方公钥验证——完整性 + 防抵赖（本身不加密）。
数字证书：CA 颁发，把公钥和身份绑定，防"假冒公钥"。
防火墙：部署在内网与外网之间，按规则过滤；IDS 只检测报警、IPS 能阻断；病毒=寄生传播，木马=后门被控，蠕虫=独立自我复制。

▶ 多媒体（1~2 题，两个公式）

采样定理：采样频率 ≥ 信号最高频率 × 2。
图像容量（字节）= 水平像素 × 垂直像素 × 颜色位深 ÷ 8；音频容量（字节）= 采样频率 × 量化位数 × 声道数 × 秒 ÷ 8。
JPEG 静态图像有损压缩；MPEG 视频压缩；PNG/GZIP 无损。

Day 4 · 数据结构 + 数学 + 强项速刷 + 全真模拟

▶ 排序算法表（每年 2~3 题，必背）

算法平均最坏稳定性
插入 / 冒泡O(n²)O(n²)稳定
选择O(n²)O(n²)不稳定
希尔≈O(n^1.3)O(n²)不稳定
快速O(n log n)O(n²)（基本有序时最差）不稳定
归并O(n log n)O(n log n)稳定
堆排O(n log n)O(n log n)不稳定
稳定性口诀："快些选堆"不稳定（快速、希尔、选择、堆）。其余（插入/冒泡/归并/基数）稳定。

▶ 数据结构高频点

二叉树：叶子数 n0 = n2 + 1（n1 为度 1 节点）；n 个节点的完全二叉树高度 = ⌈log₂(n+1)⌉；前序+中序可唯一重建二叉树（前+后不行）。
图：DFS 用栈，BFS 用队列；n 顶点邻接矩阵存储空间 O(n²)。
复杂度链：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)（教程 04 篇）。
程序语言一句话：编译=先整体翻译成目标程序再执行（报错在编译期）；解释=逐句翻译边执行、不生成目标程序；传值调用形参变化不影响实参，传地址/引用会改变实参。

▶ 数学与经济管理（4~6 分，只练套路题）

图论：最小生成树——Prim（加点）/ Kruskal（加边，先按权排序）；Dijkstra 求最短路（不能有负权边）；拓扑排序每次取入度为 0 的顶点。
决策四法：乐观（大中取大）、悲观（小中取大）、后悔值（每列最大减该值→再小中取大）、EMV 期望值（概率加权平均）。
盈亏平衡：利润 = (单价 − 单位变动成本) × 销量 − 固定成本，平衡点令利润 = 0。
计数与容斥：分类相加、分步相乘；A∪B = A + B − A∩B；全排列 n!，从 n 个取 m 个 A(n,m)=n!/(n−m)!。
统筹图：关键路径 = 最长路 = 总工期；总时差 = 最迟 − 最早（与 Day1 呼应）。

考场实战技巧（上午题专用）

① 75 题必须全部做完：单选 75 题 ×1 分，及格 45 分。空白 = 白丢分；不会的按"同一字母连蒙"（期望 ≥18 分）。
② 时间分配：上午 150 分钟，75 题平均 2 分钟/题。计算题卡住超过 3 分钟立即标记跳过。
③ 先做记忆题（软件工程/知识产权/英语/模式），再做计算题（页式/磁盘/流水线/子网），最后回头补标记题。
④ 计算题四件套（Day3 的公式）在草稿纸上开考前默写一遍——开考前有几分钟，公式遗忘是最大丢分源。
⑤ 注意"不正确的是"——上午题最阴的陷阱，圈出"不"字再答题。
