① 数据结构 6 连（最大失血点，逐个补）

先说结论：这 6 题里 4 题是"背结论"，2 题（哈夫曼、三对角）是"套公式"。今天就按下面 6 张卡顺序过，每张 5 分钟。
错1【三对角矩阵压缩】A[1..100][1..100] 三对角矩阵按行优先存入 B[1..298]，A[66][65] 的位置 k=？
知识点：三对角矩阵 = 只有主对角线及上下两条斜线非零（|i−j|≤1）。非零元素总数 = 3n−2（n=100 → 298 ✓）。每行非零个数：第 1 行 2 个、第 2~99 行各 3 个、第 n 行 2 个。
逐步解：A[66][65]：j=65=i−1 → 它是第 66 行的第一个非零元素。它前面有：第 1 行（2 个）+ 第 2~65 行（64 行 × 3 = 192 个）= 194 个 → k = 194+1 = 195（选 B）。
通用公式（i≥2）：k = 3i − 3 + (j−i+2)。验证 i=66,j=65：198−3+1 = 195 ✓
坑：第 1 行和最后一行只有 2 个非零（不是 3 个）——套 3n−2 时就体现出来了；别用对称矩阵的 n(n+1)/2 公式（那是另一题型）。
错2【哈夫曼编码】频率 a45 b13 c12 d16 e9 f5，"bee" 的编码？解码 "110001001101"？
知识点：哈夫曼树每次取权值最小的两个合并，直到只剩一棵树；左 0 右 1（约定不同答案不同，按本题约定）。
构建过程（写卷子上）：①最小两权 f5+e9=14 → ②c12+b13=25 → ③14+d16=30 → ④25+30=55 → ⑤a45+55=100（根）。
编码表：a=0，c=100，b=101，f=1100，e=1101，d=111。
bee = 101+1101+1101 = 10111011101（选 A）
解码 110001001101：从根出发，0 走左、1 走右，到叶子输出字符并回到根：1100→f，0→a，100→c，1101→e → face。
坑：合并时永远选当前最小的两个；解码按前缀码走树，走到叶子就输出回根，不会歧义。
错3【图的 BFS】无向图遍历，哪个不是广度优先序列？
知识点：BFS = 队列逐层扩散：起点出队 → 把它的邻接点按图中顺序全部入队 → 队首出队 → 再把它的未访问邻接点入队……DFS 才是用栈。
判别方法（逐选项模拟到矛盾即排除）：①看序列第一个 = 起点；②起点出队后，紧跟其后的一段必须"包含起点的全部邻接点"；③任何一个顶点 X 的邻接点，必须出现在"X 出队之后、下一个同层顶点出队之前"——出现更早就矛盾。
本题用排除法逐个模拟：A 序列起点与图结构矛盾（h 一开始就访问，但 h 只与 d 相连，c 不可能在 h 后紧跟）→ A 不是 BFS。
坑：BFS 序列里同层顶点顺序可以交换（取决于图中邻接点排列），所以别用"唯一正确序列"思维；用"邻接点必须在本层之后、下层之前"的约束去排除。
错4【图的存储与遍历复杂度】邻接矩阵 vs 邻接表
结论表（背）：
操作邻接矩阵邻接表
DFS / BFS 遍历全部O(n²)O(n+e)
找所有顶点的邻接点O(n²)（每行扫 n 个）O(n+e)
判断两顶点是否相邻O(1)（直接查格子）O(度数)
记忆：矩阵方方 n²、表加边 n+e。邻接表的 O(n*e) 不存在——正确表达是 n+e。
坑："与存储结构无关"的说法永远错——遍历耗时明显依赖存储结构。
错5【排序一趟定位置】哪些排序第一趟后一定能确定某元素的最终位置？
结论（背）：能：②冒泡（最大沉底）③简单选择（最小放头）④堆（堆顶出）⑤快排（枢轴归位）。
不能：①直接插入（一趟只有前 2 个有序）⑥归并（一趟只是局部有序段）。
本题答案 = ②③④⑤ → C。判断口诀："这一趟有没有把某个元素放到它最终的家"——插入和归并都是"逐渐变好"，没有谁一步到位。
坑：希尔排序一趟是分组插入，也不保证；题目给组合编号时用排除法先删①⑥。
错6【连通图概念】"不正确的是"哪句？
概念对号：连通 = 任意两顶点之间存在路径（绕路也算）；完全图 = 任意两顶点之间直接有边。连通图的邻接矩阵一定对称（无向图）。
判断：A"任意两点之间均有边存在"→ 那是完全图，连通图不需要 → A 不正确（选 A）；B"存在路径"= 连通定义 ✓；C"任意顶点出发可遍历全部顶点"= 连通的性质 ✓；D 邻接矩阵对称 ✓（无向图）。
坑："路径"和"边"是两个概念——有路 ≠ 有边。这类"不正确的是"题：逐项判真伪，选假的那项。

② 算法 2 连（纯对号题，背了就中）

错7【回溯法】避免无效搜索采取的策略是？
答案：剪枝函数——走一步前先判断"这条路再走下去必死"，直接不走（剪掉这根枝）。递归只是回溯的实现手段，不是"避免无效搜索"的策略。
策略识别速查（背）：Dijkstra 最短路 = 贪心；Prim/Kruskal 最小生成树 = 贪心；哈夫曼 = 贪心；0-1 背包/LCS = 动态规划；归并/快排/二分 = 分治；N 皇后/迷宫 = 回溯。
错8【Dijkstra】单源最短路径按路径长度递增次序产生，本质是（ ）策略？
答案：贪心——每一步都把"当前距离最短的那个顶点"确定为最终结果，绝不回头改（局部最优 → 全局最优，这正是贪心的定义场景）。
记忆锚："每次都抓当前最好的"= 贪心家族：Dijkstra、Prim、Kruskal、哈夫曼，四个全贪心——一张表背四道题。

③ 数据库 2 连

错9【候选码】U={A,B,C,D,E,H}，F={A→B, B→DH, A→H, C→E}，候选码？
逐步（00 篇⑦四步法）：①只在依赖左边出现的属性：A、C（B/D/E/H 都只做右边）→ 候选码必含 A 和 C；②求 (AC)⁺：A→B 得 B，B→DH 得 D、H，C→E 得 E，加上 A、C 本身 = 全部 {A,B,C,D,E,H} ✓；③所以候选码 = AC（1 个候选码，含 2 个属性）。
坑（你踩的）："候选码有（）"问的是几个候选码——A 单独、C 单独都推不满全属性，它们只是"候选码 AC 里的属性"。"1 个候选码 AC" ≠ "2 个候选码 A 和 C"，一字之差。
通用套路：只在左边出现的属性必进候选码 → 求闭包验证覆盖全部 → 数"几组"。
错10【关系代数】π1,2,3,7,8( σ2='华为Mate40'(C) ⋈ EC ⋈ E ) 这类题怎么做？
模板四步：①选表：条件里的属性在哪张表 → σ 作用于哪张（商品名在 C → σ2='HUWEI Mate40'(C)，2=C 表第 2 列商品名）；②连接：按公共属性把表连起来（C⋈EC 用商品号，再⋈E 用工号）；③投影列号：把最终要的列在"连接后的宽表"里从 1 数（E 的工号姓名、部门名 + C 的商品名 → π1,2,…）→ B；④验算：σ 的下标必须指向所选表的列，π 的下标指向连接结果的列。
坑（你踩的）：π1,2,3 vs π1,2 的差别 = 题目最终要几列（工号、姓名、部门名、商品名 → 具体列号看连接后顺序）；σ 写错表（条件是商品名却在 EC 上选）直接 0 分。

④ 软件工程 2 连

错11【内聚两空】A、B、C 有相同的程序块，块内语句无联系，取出形成模块 D → 内聚类型？"不正确的是"？
第一空：偶然内聚——"碰巧凑在一起、块内语句无任何联系" = 偶然内聚的定义，且确实是最低的内聚（该说法正确）。
第二空（选不正确的）：D"不影响模块间的耦合关系"——把公共程序块提取成 D，调用方式全变了，模块间的耦合关系恰恰会改变（降低），说"不影响"不成立。
坑（你踩的）："不正确的是"题——你选了"正确"的陈述。先在题干圈"不正确/不包括/错误的是"，再逐项打 ✓✗，选打的那个。
错12【详细设计审查】详细设计结束后，重点审查的内容不包括？
答案：数据流图（选它）——DFD 是需求分析阶段的产物（画系统数据流动），到详细设计早就定稿了。详细设计审查的是：算法（每个模块怎么算）、数据结构、接口、界面。
阶段产物对号表（背）：
阶段核心产物
需求分析数据流图 DFD、数据字典、E-R 图
概要设计模块结构图、层次图、接口说明
详细设计算法流程/伪码、数据结构、界面
测试测试计划、测试用例

⑤ 面向对象 1

错13【三类对象】"系统与参与者之间的接口，从参与者收集信息并转换为实体/控制对象可用的形式" → ？
答案：边界对象。OO 分析把对象分三类，口诀：边界管接口、控制管逻辑、实体管数据：
· 边界对象（Boundary）：系统与参与者（人/外部系统）之间的接口——界面、输入输出转换（题干"接口+收集信息+转换"全是它的信号词）；
· 控制对象（Control）：业务逻辑、流程协调；
· 实体对象（Entity）：要持久保存的数据（如订单、处方）。
坑：看到"接口/界面/转换"选边界；看到"计算/流程/协调"选控制；看到"存储/信息本身"选实体。
