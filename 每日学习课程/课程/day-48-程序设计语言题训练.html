下午题 · 算法案例

最长递增子序列动态规划

dp[i] = 以 a[i] 结尾的最长递增子序列长度
for i = 0..n-1:
    dp[i] = 1
    for j = 0..i-1:
        if a[j] < a[i]:
            dp[i] = max(dp[i], dp[j] + 1)
  1. 为什么dp[i]初值为1？
  2. 状态转移为什么要求a[j]<a[i]？
  3. 最终答案如何从dp数组得到？
  4. 时间和空间复杂度分别是多少？
展开采分点答案

① 单独一个元素本身就是长度1的递增子序列。

② 只有前一个元素更小，a[i]才能接到其递增子序列之后。

③ max(dp[0..n-1])。

④ 两层循环为O(n²)，dp数组为O(n)。

迁移训练 · 不看答案

今天的新场景任务

比较贪心与动态规划：解释为什么最长递增子序列不能只取当前最小元素。

验收：写出判断依据，而不是只写最终术语。
