  • 用途：SRAM 做 Cache，DRAM 做主存

  • 整除得页号，取余留偏移；查表换帧号，拼出新地址
  • 偏移不变，页号换帧号：物理地址 = 帧号 × 页大小 + 偏移

🌳 数据结构 · 完全二叉树

  • 叶子定，求总数：最多乘二，最少乘二减一
  • 总数定，求叶子：对半向上取整
  • 单孩结点要么 0，要么 1
  • 顺序存储：父 i，左 2i，右 2i+1；空结点也占位，下标不能跳

🌲 数据结构 · 树的叶子数通用公式

  • 所有度数加起来 +1，减去非叶子结点总数 = 叶子数
  • 更快形式：叶子数 = 1 + Σ(度数-1)×该度数结点数（n₁ 不出现）
  • 二叉树特例即 n₀ = n₂ + 1

🕸️ 数据结构 · 图

  • 邻接矩阵对称 = 无向图，不对称 = 有向图
  • 拓扑排序前提：有向无环图（DAG），至少一个入度 = 0 的点
  • 强连通：任意两点互相可达
  • 图有环 = 没有拓扑序列

🗄️ 数据库 · 范式判定

  • 1NF：单元格不拆分
  • 2NF：字段不能只靠组合主键的一半推出；单主键天然 2NF
  • 3NF：非主属性不能隔层推导（干掉传递依赖）
  • BCNF：所有决定方都必须是候选键，主属性也不能互相依赖

💾 计算机组成 · SRAM vs DRAM

一句话口诀

S 快贵不用刷，D 慢便宜要刷新，D 集成更高

📌 展开对照（口诀背后的考点）

对比项SRAM（静态存储器）DRAM（动态存储器）
存储原理触发器电容存电荷
速度快慢
价格贵便宜
是否刷新不需要需要定时刷新（电容漏电）
集成度低高
主要用途Cache（高速缓存）主存（内存条）

🎯 典型真题自测

1.Cache 一般由哪种存储器构成？▶

SRAM。快但贵，适合小容量高速场景 → Cache；主存容量大、要求便宜 → DRAM。

2.DRAM 需要刷新的原因是？▶

DRAM 用电容存储电荷，电容会漏电，须定期刷新保持数据；SRAM 用触发器，只要不掉电就不丢失，无需刷新。

📄 操作系统 · 分页地址变换

口诀

整除得页号，取余留偏移；查表换帧号，拼出新地址

📌 四步展开（对应口诀）

  1. 整除得页号：页号 = 逻辑地址 ÷ 页大小（取商）
  2. 取余留偏移：页内偏移 = 逻辑地址 mod 页大小（取余）
  3. 查表换帧号：拿页号查页表 → 得物理帧号（也叫物理块号）
  4. 拼出新地址：物理地址 = 帧号 × 页大小 + 页内偏移

关键：偏移量原样照抄，变的只是页号 → 帧号

⚡ 快解技巧（页大小是 2 的幂时免除法）

  • 页大小 4KB = 212 → 逻辑地址二进制低 12 位 = 偏移，其余高位 = 页号
  • 页大小 1KB = 210 → 低 10 位 = 偏移
  • 页大小 2KB = 211 → 低 11 位 = 偏移

🎯 典型真题自测

1.页大小 4KB，逻辑地址 8452，页号 2 对应物理块号 8，求物理地址。▶

页号 = 8452 ÷ 4096 = 2（商），偏移 = 8452 − 2×4096 = 260

物理地址 = 8 × 4096 + 260 = 33028

2.页大小 1KB 的分页系统，逻辑地址 2053 的页号和页内偏移分别是？▶

2053 ÷ 1024 = 商 2 余 5 → 页号 2，偏移 5

快解：1KB = 210，2053 的二进制低 10 位即偏移

🌳 数据结构 · 完全二叉树 5 条必考公式 考频 ⭐⭐⭐⭐⭐

基础符号定义

  • n0：叶子结点（度 = 0）
  • n1：度为 1 的结点（只有 1 个孩子）
  • n2：度为 2 的结点（左右孩子都有）
  • N：整棵树总结点数

公式 1｜二叉树通用恒等式（所有二叉树都成立）

n0 = n2 + 1
  • 推导：n2 = n0 − 1
  • 含义：叶子结点永远比度为 2 的结点多 1 个

公式 2｜完全二叉树独有约束

n1 = 0  或  n1 = 1
  • 重点：完全二叉树最多只能有 1 个结点只有左孩子，不可能出现 2 个及以上 n1

公式 3｜总结点公式

N = n0 + n1 + n2   = n0 + n1 + (n0 − 1) N = 2n0 − 1 + n1

两种极端（选择题高频）

  1. 已知叶子 n0，求最大结点数（取 n1 = 1）：
    Nmax = 2n0

    例：n0 = 124 → Nmax = 248

  2. 已知叶子 n0，求最小结点数（取 n1 = 0）：
    Nmin = 2n0 − 1

    例：n0 = 124 → Nmin = 247

公式 4｜已知总结点 N，反推叶子 n0

n0 = ⌈ N2 ⌉（向上取整）
  • N 为偶数：n0 = N/2，此时 n1 = 1
  • N 为奇数：n0 = (N+1)/2，此时 n1 = 0

公式 5｜顺序存储下标关系（从 1 开始编号）

父 i，左 2i，右 2i+1；空节点也要占位置，不能跳过下标

  • 父结点下标 = ⌊i/2⌋
  • 判断有无孩子：2i > N 时 i 是叶子（无左孩子）；2i+1 > N 时只有左孩子
  • 衍生结论：N 个结点中，最后一个非叶子（分支）结点编号 = ⌊N/2⌋，其后全是叶子
  • 变体（从 0 开始编号，如 C 数组）：左 2i+1，右 2i+2，父 ⌊(i−1)/2⌋

✨ 速记口诀

叶子定，求总数：最多乘二，最少乘二减一

总数定，求叶子：对半向上取整

完全二叉树，单孩结点要么 0，要么 1

顺序存储：父 i 左 2i 右 2i+1，空位不能跳

🎯 典型真题自测

1.某完全二叉树共有 700 个结点，则叶子结点数为多少？▶

n0 = ⌈700/2⌉ = 350（N 为偶数，n1 = 1）

2.一棵完全二叉树上有 701 个结点，则叶子结点数为多少？▶

n0 = ⌈701/2⌉ = 351（N 为奇数，n1 = 0）

3.700 个结点的完全二叉树按层序从 1 编号，编号为 100 的结点其左、右孩子编号分别是多少？▶

左孩子 2×100 = 200，右孩子 2×100+1 = 201；因 201 ≤ 700，两个孩子都存在。

4.700 个结点的完全二叉树按层序从 1 编号，最后一个非叶子结点的编号是多少？▶

⌊700/2⌋ = 350，编号 351~700 全是叶子（共 350 个，与公式 4 呼应）。

🌲 数据结构 · 树的叶子数通用公式

速记公式（直接背）

n0 = 1 + Σ i·ni − Σ ni  （i 取 1 ~ k，ni 为度为 i 的结点个数）
  • 展开即：n0 = 1 + (1·n1 + 2·n2 + … + k·nk) − (n1 + n2 + … + nk)
  • 口诀：所有度数加起来 +1，减去非叶子结点总数 = 叶子数

📌 更简形式（做题更快）

n0 = 1 + Σ (i − 1)·ni  （i 取 2 ~ k）
  • 即：叶子数 = 1 + Σ(度数 − 1) × 该度数结点数，n1 根本不出现
  • 二叉树特例：n0 = 1 + n2，正是经典恒等式 n0 = n2 + 1 —— 本公式是它的推广

🎯 典型真题自测

1.树 T 的度为 4，度为 1、2、3、4 的结点个数分别为 4、2、1、1，则 T 中的叶子结点数为多少？▶

原式：n0 = 1 + (1×4 + 2×2 + 3×1 + 4×1) − (4+2+1+1) = 1 + 15 − 8 = 8

快解：n0 = 1 + 1×2 + 2×1 + 3×1 = 8

2.一棵度为 3 的树中，度为 3 的结点有 2 个，度为 2 的结点有 1 个（度为 1 的结点数未知），则叶子结点数为多少？▶

6。n1 不影响结果：n0 = 1 + 1×1 + 2×2 = 6。

🕸️ 数据结构 · 图论基础速记

速记口诀

  1. 邻接矩阵对称 = 无向图；不对称 = 有向图
  2. 拓扑排序存在的前提：有向无环图（DAG），必须至少存在一个入度 = 0 的点
  3. 强连通：任意 u 到 v、v 到 u 都有路
  4. 一旦图存在环：没有拓扑序列

📌 关联结论（做题常用）

  • 无向图：顶点 i 的度 = 邻接矩阵第 i 行（列）元素之和（矩阵对称，行列相同）
  • 有向图：第 i 行之和 = 出度，第 i 列之和 = 入度
  • n 个顶点的无向完全图：边数 = n(n−1)/2
  • n 个顶点的有向完全图：弧数 = n(n−1)
  • 拓扑序列不唯一；做法：每步删去入度为 0 的点及其出边

🎯 典型真题自测

1.若有向图的拓扑序列不存在，则该图一定？▶

存在环。拓扑排序仅对 DAG 成立；有环则环上各顶点入度永远 > 0，无法删空。

2.37 个结点的有向完全图有多少条弧？▶

n(n−1) = 37 × 36 = 1332 条。

🗄️ 数据库 · 范式判定 1NF / 2NF / 3NF / BCNF 考频 ⭐⭐⭐⭐⭐

基础名词先看懂

  • 主键：唯一标识一行的属性
  • 主属性：出现在候选键里的字段
  • 非主属性：不在候选键里的字段
  • 部分依赖：主键是组合键，只靠主键一部分就能推出某个字段
  • 传递依赖：A → B，B → C，且 B 不反过来推 A，则 C 传递依赖 A

四条范式判定规则（逐条往上套）

✅ 1NF（第一范式）

规则：列不可再分，单元格只能存单个值

  • 禁止：一个格子写多个数据（比如地址 福建,厦门 放同一格）
  • 只要是一张正常设计的二维表，基本都满足 1NF

✅ 2NF（第二范式）

前提：先满足 1NF ｜ 规则：消除「非主属性对主键的部分函数依赖」

  1. 主键是单个字段：天然满足 2NF
  2. 主键是组合键 (A,B)：若 (A,B) → C 且 A → C（C 只依赖 A）→ 部分依赖，不满足 2NF
  • 2NF 只禁止【组合主键带来的局部依赖】，传递依赖依然允许

✅ 3NF（第三范式）

前提：先满足 2NF ｜ 规则：消除「非主属性对主键的传递依赖」

  • 不允许出现：主键 → X，X → 非主属性
  • 做题实例：教师号 → 岗位，岗位 → 薪资。薪资是非主属性，传递依赖主键 → 不满足 3NF，只到 2NF
  • 达不到 3NF 的后果：数据冗余、插入异常、删除异常、修改异常

✅ BCNF（巴斯-科德范式，增强版 3NF）

前提：先满足 3NF ｜ 规则：消除「主属性之间的传递 / 部分依赖」

  • 3NF 只管非主属性；BCNF 连主属性之间的依赖都要清理干净
  • 软考小结论：BCNF 一定是 3NF；3NF 不一定是 BCNF

🧾 极简判断口诀（做题直接背）

  1. 1NF：单元格不拆分
  2. 2NF：组合主键，字段不能只靠主键一半推出；单主键天然 2NF
  3. 3NF：非主属性不能隔一层推导（干掉传递依赖）
  4. BCNF：所有决定方都必须是候选键，主属性也不能互相依赖

一句话快速区分

  • 1NF：单元格干净
  • 2NF：没有"沾一半主键就能确定的值"
  • 3NF：没有二手数据（传递得来的值）
  • BCNF：连主键内部都不能互相决定

🎯 典型真题自测

1.关系模式 R(A, B, C)，函数依赖 F = {A→B, B→C}，则 R 最高属于第几范式？▶

2NF。单属性主键 A 天然满足 2NF；但 A→B→C，C 传递依赖 A → 不满足 3NF。

2.关系模式 R(A, B, C)，函数依赖 F = {AB→C, C→B}，则 R 最高属于？▶

3NF。候选键为 AB 和 AC，A、B、C 全是主属性（无非主属性）→ 满足 3NF；但 C→B 的决定方 C 不是候选键 → 不满足 BCNF。
