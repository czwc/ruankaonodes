# 📋 第 3 页:下午题套路速记

## 题 1 · DFD 数据流图

**四要素**:矩形=外部实体,圆形=加工,双横=数据存储,箭头=数据流

**找缺失三板斧**:
1. 对比父子图(必须一模一样)
2. 找外部实体与加工的箭头
3. 找加工与数据存储的箭头(题目说"保存"就要有箭头)

**改错话术**:
- 黑洞:只有输入无输出
- 奇迹:只有输出无输入
- 不平衡:父子图数据流不一致
- 命名错误:数据流用动词(应改名词)

## 题 2 · 数据库设计

**E-R 转关系**:
- 1:1 → 任一方加外键
- 1:n → 1 的主键加到 n 方
- m:n → 新建关系表(双方主键联合主键)

**范式判断**:
- 部分依赖 → 不满足 2NF
- 传递依赖 → 不满足 3NF

## 题 3 · UML 建模

**类图三层**:类名 / 属性(名词)/ 方法(动词)

**可见性**:`+`public `-`private `#`protected

**用例关系**:
- include = 必然发生
- extend = 可能发生
- 泛化 = 继承

## 题 4 · 算法填空

**三招蒙分**:
1. 找上下文未用变量
2. 死记模板:
   - 二分:`while(low<=high)` `mid=(low+high)/2`
   - 冒泡:外 `i<n-1`,内 `j<n-1-i`
3. 看中文注释翻译

**复杂度速判**:
- 单层 for → O(n)
- 双层嵌套 → O(n²)
- 每次折半 → O(log n)
- 分治递归 → O(n log n)

## 题 5/6 · 设计模式代码填空

**五步填空**:
1. 识别模式类型(创建/结构/行为)
2. 找接口/抽象类的方法签名
3. 创建对象填 `new XxxImpl()`
4. 调用方法照抄接口名
5. 看返回类型填 return

**高频模式代码骨架**:
- 单例:`private static` + `getInstance()`
- 工厂:`createXxx()` 返回 `new XxxImpl()`
- 观察者:`attach()` + `notify()` 调 `update()`
- 策略:`setStrategy()` + `strategy.execute()`
