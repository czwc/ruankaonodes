# 50 天课程表（详细版）

> 每日结构：热身回顾（从「待复习队列」抽 1~2 道到期题）→ 3~5 知识块（讲→问→答）→ 当堂小测（3~5 题）→ 口诀沉淀 → 课后作业
> 「作业」列 = 推荐学生课后自学的本地 HTML 课程（`每日学习课程/课程/` 下），10~20 分钟。
> 动态机制：每 5 天（Day 5/10/15/20/25/30/35/40）课后加 10~15 分钟"错题回炉"；模块小测 <60% 次日插"巩固日"（原计划顺延）。详见 `review-system.md`。
