# 下午题（案例分析）五大题型解题套路

> 6 道大题：试题一~四必答，试题五（C++）/试题六（Java）二选一。每题 15 分，共 75 分，45 分及格。
> 教学顺序：先讲套路 → 再逐问实战 → 按评分点给分。

## 题型 1 · 数据流图 DFD（试题一，必答）⭐⭐⭐

**四大要素**：外部实体（矩形/立方体）、加工（圆/圆角矩形）、数据存储（双横线/开口矩形）、数据流（箭头）。

**解题套路**：
1. 先读题干叙述，圈出"人/外部系统"→ 外部实体；圈出"文件/表/库"→ 数据存储；圈出动词短语 → 加工
2. **父子图平衡**：父图的输入输出数据流 = 子图边界数据流，多一条少一条都算错
3. 补缺失数据流三步定位：
   - 看加工是否"有进无出/有出无进"（每个加工必须有进有出）
   - 看数据存储是否没人读/没人写
   - 对照父图找子图缺的流
4. 数据流必须命名（名词），加工必须命名（动词+宾语），不能只写"数据""处理"

**常见失分点**：把外部实体画成加工；数据流箭头方向反；忽略"父图有的流子图必须有"。

## 题型 2 · 数据库设计（试题二，必答）⭐⭐⭐

**解题套路**：
1. E-R 建模：名词→实体/属性，动词→联系；联系上标 1:1 / 1:n / m:n
2. E-R 转关系模式规则：
   - 1:1 → 任意一方并入对方主键
   - 1:n → "n 端"并入"1 端"主键
   - m:n → 必须单独建表，主键 = 两端主键组合
3. 补充关系模式：先找已有属性，缺的就是联系产生的外键
4. 主键判断：能唯一标识且不含冗余；外键 = 引用其他表主键的属性
5. SQL 补全：重点练 CREATE TABLE（主外键约束）、SELECT 连接+分组+子查询

**常见失分点**：m:n 联系忘了建独立表；外键方向搞反；SQL 的 GROUP BY 漏列。

## 题型 3 · UML 建模（试题三，必答）⭐⭐⭐

**常考图**：用例图、类图为主，序列图/状态图/活动图轮换。

**解题套路**：
1. 用例图三要素：参与者（小人）、用例（椭圆）、关系
   - include（包含）：必做子用例，箭头指向子用例
   - extend（扩展）：可选/异常才做，箭头指向基用例
   - 泛化：参与者或用例的"继承"
2. 类图：类名/属性/操作三栏；类关系强度 **组合 > 聚合 > 关联 > 依赖**
   - 多重度：1、0..1、0..*、1..*（看题干"一个X包含多个Y"）
3. 序列图：看消息顺序，同步=实心箭头，返回=虚线
4. 状态图：事件触发迁移，注意 guard 条件 [ ]

**常见失分点**：include/extend 箭头方向搞反（记：**include 指向被包含者，extend 指向基用例**）；多重度写反。

## 题型 4 · 算法设计（试题四，必答）⭐⭐⭐⭐

**形式**：C 代码 + 5~6 个填空 + 1 问算法设计思想 + 1 问时间/空间复杂度。

**解题套路**：
1. **先读主函数**：搞清输入输出和整体流程，别一头扎进填空
2. 盯住"填空行的变量在前后文怎么用"：填空 = 前文准备 + 后文使用的连接点
3. 常考算法思想识别：
   - 递归：找递归出口 + 递归式
   - 分治：二分/归并，看 mid
   - 贪心：每步取局部最优（排序+选取）
   - 动态规划：状态转移方程，看 dp[i] 与 dp[i-1]/dp[i-1][j] 的关系
   - 回溯：递归+撤销选择
4. 复杂度：看循环嵌套层数（与问题规模 n 相关的）

**常见失分点**：不看主函数直接填；边界条件（i<n 还是 i<=n）想当然；复杂度只写 O(n) 不看嵌套。

## 题型 5/6 · 面向对象程序设计（试题五 C++ / 试题六 Java，二选一）⭐⭐⭐⭐

**形式**：一段面向对象代码 + 类图/说明 + 5 个填空。C++ 与 Java 题同构，选熟悉的语言。

**解题套路**：
1. 先看类图/说明，明确类的职责与关系（常考设计模式：策略/观察者/装饰/适配器/桥接/模板方法/状态）
2. 填空高频位置：
   - 虚函数/抽象方法声明（C++: virtual ... = 0；Java: abstract）
   - 子类重写（C++: override 可选；Java: @Override）
   - 多态调用：通过基类指针/引用调子类方法
   - 构造函数与初始化列表
   - 接口实现（Java: implements；C++: public 继承）
3. 设计模式题：先识别模式（看类关系），再按"角色"填空

**常见失分点**：C++ 忘 virtual 导致多态失效；Java 接口方法默认 public；构造顺序错。

## 评分与时间分配（模考用）

- 总时长 150 分钟，5 题 × 约 28 分钟，留 10 分钟检查
- 每题先做有把握的小问，填空题按空给分，**不会的空也要写最可能的**（如复杂度、变量名）
- 及格策略：DFD + 数据库 + UML 三题拿 36+，算法与程序设计各拿 6+ 即稳过
