# 标准讲义库（固定算例 + 固定验证题）

> **用途**：保证任何会话/任何设备讲同一知识块时，口径、算例、出题完全一致。
> **格式**：每个块 = 固定算例（讲解用，一步不跳）+ 固定验证题（讲完必出）+ 备选变式题。
> **维护规则**：讲到一个新块，课后必须把当次用的算例和题沉淀进来；学生错题附错因，作为下次讲解的陷阱提示。
> **状态标记**：✅=已实际授课验证；🆕=新沉淀待下次验证。

## Day 1 · 计算机组成（一）

### 块1 CPU 组成 ✅
- **验证题**：下列不属于 CPU 组成部分的是：运算器 / 控制器 / **主存储器** / 寄存器组 → C
- **陷阱**：主存在 CPU 外；"Cache 属于 CPU"也是常见干扰项（严格说在 CPU 芯片内但体系结构上独立于 CPU 核心，题目问"CPU 两大部件"时答运算器+控制器）

### 块2 运算器四大件 ✅
- **验证题**：为 ALU 提供并暂存运算中间结果的部件 → **累加器 AC**（干扰项：IR/PC/PSW）
- **陷阱**：PSW 记录状态（进位/溢出/零标志），不存数据

### 块3 控制器四大件 ✅
- **验证题**："PC 自动加 1"发生在 → **取指令之后、译码之前**（B）
- **陷阱**：不是"执行完才加 1"；IR 存当前指令，PC 存下条地址

## Day 2 · 计算机组成（二）

### 块1 进制转换 ✅
- **算例**：45 → 101101：45=32+8+4+1（权重法）或除2取余：45÷2=22余**1**、22÷2=11余**0**、11÷2=5余**1**、5÷2=2余**1**、2÷2=1余**0**、1÷2=0余**1** → 倒着读 **101101**
- **学生错题实录**：曾错选 110101（余数正着读）；错因=忘倒序。自检法：奇数末位必为 1；权重加和验算
- **验证题**：37 → 100101（复习通过）；1011011₂ → 0101 1011 → **5B**（十六进制，4 位分组）
- **变式题**：0.25 → 0.01₂（乘 2 取整正着读）

### 块2 原码/反码/补码/移码 ✅
- **算例**：-46（8 位）：46=00101110 → 原码 10101110 → 反码 11010001 → 补码 **11010010**
- **验证题**：-46 的补码 → B（11010010）；干扰项 A=反码、C=原码
- **变式题**：-1 的补码 = **11111111**（全 1 即 -1）

### 块3 定点数表示范围 ✅
- **算例**：8 位：原码 -127~+127（0 占两坑）；补码 -128~+127（0 唯一，左端多一格）
- **验证题**：8 位原码范围 → **B（-127~+127）**

## Day 3 · 计算机组成（三）

### 块1 浮点数表示 + IEEE 754 ✅
- **概念题**：表示范围由**阶码位数**决定，精度由**尾数位数**决定（学生曾首答晃：选尾数——复习包见 progress 队列）
- **带练算例（固定）**：10.25 → 1010.01₂ → 1.01001×2³ → S=0，E=3+127=130=10000010，M=01001000…0 → `0｜10000010｜01001000000000000000000` = **0x41240000**
- **变式题（固定）**：-6.5 → 110.1₂ → 1.101×2² → `1｜10000001｜10100000000000000000000` = **0xC0D00000**（学生已独立答对 ✅）
- **陷阱**：阶码是"真实指数+127"不是移码；十六进制按 4 位分段拼

### 块2 寻址方式 ✅
- **固定题面（一张表打天下）**：内存[100]=200，内存[200]=500；R1=100；指令地址码 A=100
- **验证题**：直接寻址=**200**；寄存器间接寻址=**200**；间接寻址=**500**（学生全对 ✅）
- **变式题**：立即寻址下操作数=**100 本身**（数在指令里）
- **陷阱**：直接 vs 寄存器间接答案可能相同但路径不同；"间接"要跑两趟

### 块3 RISC vs CISC ✅
- **验证题**：不属于 RISC 的是 → **采用微程序控制**；关于 RISC 正确的是 → **大多数指令单周期完成**（学生两次全对 ✅）
- **答题套路**：找异类——定长/少/单周期/流水线/组合逻辑/寄存器多是 RISC 标签；"微程序"= CISC

### 块4 指令流水线 ✅
- **固定工作图**：3 阶段（取指/分析/执行）各 1 单位，3 条指令共 **5 个单位时间**（阶段数+指令数-1）
- **验证题**：流水线说法正确的是 → **各阶段执行时间相同时效率最高**（学生首答 D 错、引导后改对 ⚠ 复测包见 progress 队列）
- **陷阱**：流水线不缩短单条指令时间；不是串行执行；瓶颈=最慢阶段

## Day 5 · 计算机组成（五）

### 块1 流水线计算 ✅
- **算例（固定）**：5 段各 10ns、10 条 → Δt=10、T=(5+10−1)×10=140ns、串行=500ns、S≈3.57、TP=10/140；变式算例：4 段各 20ns、20 条 → T=460ns、S=1600/460≈3.48（学生三步独立答对 ✅）
- **验证题（固定）**：4 段各 20ns 执行 20 条 → 周期 20ns、总时 460ns、加速比 ≈3.48
- **变式预警**：各段不等长（1/2/3ns）→ 周期=max=3ns；串行分子用各段之和（6n）不是最长×段数

### 块2 Cache 命中率与映像 ✅
- **算例（固定）**：h=90%、tc=10、tm=100 → 19ns；h=95%、tc=5、tm=100 → 9.75ns（学生两问独立答对 ✅）
- **验证题（固定）**：h=95% 计算 9.75ns；"任意位置"=全相联（B）；"组内任意/折中"=组相联
- **口诀**：命中乘快加未中乘慢；直接死板、全相联自由、组相联折中

### 块3 存储层次 + 磁盘 🆕（断点：验证题未作答）
- **算例（固定）**：6000rpm → 一圈 60/6000=10ms → 平均旋转延迟=半圈 5ms → 存取=寻道8+旋转5+传输1=14ms
- **验证题（待学生作答）**：7200rpm → 平均旋转延迟 60/7200/2 ≈ **4.17ms**；磁头移动到目标磁道=**寻道时间**
- **位示图**：Day 8 详讲，本块只预热"1 位表示 1 块占用状态"
- **口诀**：寻道转半圈再传输；转速定半圈，六十除转速再减半

## Day 7 · 操作系统（二）

### 块1 死锁四条件与处理策略 ✅
- **算例（固定）**："不属于四条件"→ 干扰项"可抢占"（反了，是不可剥夺）；"破坏条件属于避免"✗（属于预防）
- **验证题（固定）**：错误叙述选"破坏不可剥夺条件属于避免"→ C（学生独立答对 ✅）；四条件默写全对 ✅
- **口诀**：互斥请求不剥夺，循环等待死锁锁；一次性申请破保持，银行家边走边躲

### 块2 银行家算法 ✅
- **算例（固定）**：总10，P1(占3需5)/P2(占2需3)/P3(占2需4) → 剩3 → P2→回收→5 → P1→回收→8 → P3 → 安全序列 **P2→P1→P3**
- **验证题（固定）**：总8，P1(占2需4)/P2(占2需3)/P3(占2需2) → 安全，序列 P3→P2→P1（学生独立答对 ✅ 且自主发现序列不唯一）
- **陷阱**：不安全 ≠ 必死锁；安全序列不唯一

### 块3 分页与分段 🆕（断点：学生反馈未学会，续课换讲法）
- **算例（固定）**：页大小 4KB、逻辑地址 8452、页号 2→块号 8 → 物理 = 8×4096+260 = 33028；快解：4KB=2¹² 低 12 位偏移
- **验证题（待学生作答）**：页 1KB、逻辑地址 2053、页 2→块 5 → 页号=2053÷1024=2、偏移=5、物理=5×1024+5=**5125**；概念题→C（页内部碎片、段外部碎片）
- **续课讲法**：先教快解（2 的幂时低位照抄），再回"整除得页号"公式；类比"撕书成小册子 vs 按章节装订"

## Day 4 · 计算机组成（四）

### 块1 奇偶校验 ✅
- **算例**：数据 1011010（4 个 1，偶数）；偶校验 → 校验位补 0 放最高位 → 码字 **01011010**
- **验证题**：偶校验生成 01011010；收到 00110100（3 个 1，奇数，违约）→ **能检测出** → 答案 C（学生首答 B 错在漏数"1"的个数，引导后答对 ⚠）
- **陷阱**：偶数个位同时出错检测不出；纠错不是它的功能

### 块2 海明码 ✅
- **算例（固定）**：数据 1011，k=3（2³=8≥4+3+1）；码字位置 1~7 = P1 P2 D1 P4 D2 D3 D4；P1 管 1,3,5,7 → 0；P2 管 2,3,6,7 → 1；P4 管 4,5,6,7 → 0；码字 **0110011**；纠错：各组校验结果拼二进制=出错位置号
- **"为什么"讲解（必须讲）**：位置号写二进制（身份证），P1=个位巡逻员管身份证个位为 1 的位置（1,3,5,7）；出错时报警组合 S4S2S1 恰好=出错位置的身份证号。演示：0110011 第 5 位出错 → P1、P4 报警 → 101=5；第 6 位出错 → P2、P4 报警 → 110=6（学生此题独立答对 ✅）
- **验证题**：信息位 8 位，纠 1 位错 → 2ᵏ≥8+k+1 → k=4 → 答案 **B**（学生答对但未写过程，追问后确认）
- **结课题（固定）**：数据 1100 → 码字 **0111100**（学生首答 0011100，P2 漏数位置 3 ❌ → 错题本 id 37）；变式：数据 1001 → **0011001**（学生独立答对 ✅）
- **陷阱**：位置 3 同时属于 P1+P2 组、位置 7 属于全部三组，清点时最容易漏

### 块3 CRC ✅
- **算例（固定）**：数据 10110，G(x)=x³+1（1001）→ r=3 → 10110 补 3 个 0 = 10110000 → 模 2 除法：10110000⊕1001(对齐位1)=00100000 → 窗口1000⊕1001=0001 → 余数 **100** → CRC 码 = **10110100**（自检：10110100÷1001 余 000）
- **验证题**：CRC 说法正确的是 → **生成多项式最高次幂为 3 时校验码 3 位**（干扰项：纠错是海明码功能、穿插是海明码摆位、校验码由余数确定不是商）→ 答案 C（学生独立答对 ✅）

### 块4 可靠性计算 ✅
- **公式**：串联 R=R₁×R₂×…；并联 R=1−(1−R₁)(1−R₂)…；混合从里往外（先并联小块再串联大块）；MTBF=1/λ
- **算例（固定）**：两个 0.9 串联=0.81；两个 0.9 并联=0.99；两个并联组（各两个 0.9）串联=0.99×0.99=0.9801
- **验证题**：两子系统串联（各由两个 0.9 并联）→ **0.9801**（学生答对 ✅）；变式：三个 0.9 并联 → 1−0.1³=**0.999**（学生答对 ✅）
