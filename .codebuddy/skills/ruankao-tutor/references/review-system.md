# 复习系统（间隔重复 + 错题回炉 + 巩固日 + 阶段复盘）

> 目标：学过的不忘、错过的不再错。所有数据落在 progress.md，跨会话持续生效。

## 一、间隔重复排期（艾宾浩斯）

所有新学考点与错题自动进入「待复习队列」：

| 对象 | 复习间隔 | 形式 |
|---|---|---|
| 新学考点 | 当天小测 → +1 天 → +3 天 → +7 天 | 每课开场热身，1 道快问快答 |
| 错题 | +1 天 → +3 天 → +7 天 → +15 天 | 重做原题或同类变式 |
| 口诀 | +3 天 → +7 天 → 考前串讲 | 口诀填空 / 接龙 |

**执行规则**：
- 到期复习在每课开场（SKILL.md 5.0）进行，每次抽 1~2 题，控制在 3 分钟内
- 到期答对 → 进入下一间隔；答错 → 间隔重置（回到 +1 天）并补记错因
- 队列写在 progress.md「待复习队列」表，每次课后更新；到期日 = 学习日 + 间隔
- 当日到期题超过 5 道 → 只抽最旧的 2 道进热身，其余顺延到"错题回炉"时段处理

## 二、错题回炉（每 5 天固定时段）

- 时间点：Day 5/10/15/20/25/30/35/40 的课后，10~15 分钟
- 从错题本抽**到期错题**重做（优先"考前必看"标记）
- 全对 → 移出错题本；仍错 → 保留、间隔重置、标"考前必看"
- 回炉结果记入 progress.md「错题本」表的重做列

## 三、巩固日（动态插入）

**触发**：某模块当堂小测 <60%（分级 ❌薄弱）

**结构**（约 40 分钟）：
1. 薄弱点重讲：换一个类比、换一种讲法，不重复上次的表述
2. 10 题加练：从该模块错题 + 同类新题混合
3. 复测 5 题：≥80% 才算过关；不过关则次日再插一个巩固日（最多连插 2 次，仍不过 → 列入长期薄弱点，冲刺期重点盯）

**排期规则**：
- 距考试 ≥15 天 → 次日插入巩固日，原计划整体顺延 1 天
- 距考试 <15 天 → 不顺延，改为当日压缩：巩固 30 分钟 + 当日新课照常

## 四、阶段复盘（三个验收点）

| 时点 | 内容 | 产出 |
|---|---|---|
| Day 25 一阶段验收 | 50 题综合模拟 + 讲评 | 「模块掌握度」全景表 → 二轮侧重依据 |
| Day 40 二阶段验收 | 下午题得分率分析 + 补强 | 五大题型强弱排序 → 冲刺侧重依据 |
| Day 46~47 错题大复盘 | 上午/下午错题分场二刷 | "考前必看"最终清单 |

## 五、考前"最后一眼"清单（Day 50 生成）

汇总三样东西，让学生考前一晚和考场外看：
1. 仍标"考前必看"的错题（考点级摘要，不是整题）
2. 全部口诀（对照《做题笔记.md》口诀汇总区）
3. 高频公式清单（对照《软件设计师高频公式详解与例题.md》）

## 六、复习模式（学生随时触发）

学生说"复习/巩固/回炉"时，按优先级：
1. 先清「待复习队列」到期题
2. 再按「薄弱点」清单加练（每点 3 题）
3. 学生点名某模块 → 快速串讲（口诀过一遍）+ 5 题验证
4. 复习结果照常写入 progress.md
