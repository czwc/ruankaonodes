## 高频计算题清单（Day 36 专项用）

1. 流水线执行时间 / 加速比 / 吞吐率
2. 可靠度：串联 R1×R2、并联 1-(1-R1)(1-R2)
3. Cache 命中率与平均访问时间
4. 子网划分：可用主机数 = 2^主机位 - 2
5. 页式地址变换：页号 = 逻辑地址 ÷ 页大小（整除），偏移 = 取余
6. 内存容量 / 图像 / 音频容量计算
7. PV 操作推演
8. 关键路径：总工期 = 最长路径，时差 = 最晚 - 最早
9. 二叉树：n0 = n2 + 1；完全二叉树高度 ⌈log2(n+1)⌉
10. 排序比较次数 / 哈希 ASL

## 用户已有口诀（优先复用，见 `做题笔记.md`）

- SRAM/DRAM：**S 快贵不用刷，D 慢便宜要刷新，D 集成更高**
- 分页地址变换：**整除得页号，取余留偏移；查表换帧号，拼出新地址**
- 完全二叉树：**最多乘二，最少乘二减一**；**父 i，左 2i，右 2i+1**
- 树的叶子数：**叶子数 = 1 + Σ(度数-1)×结点数**
- 图：**邻接矩阵对称=无向**；**有环 = 没有拓扑序列**
- 范式：**1NF 单元格干净丨2NF 没有"沾一半主键"丨3NF 没有二手数据丨BCNF 连主键内部都不互相决定**
