📖 入门必读:怎么"看懂"一份代码题

软考下午题代码填空不是让你从零写代码,而是给你 90% 完整的代码,挖几个空让你填。只要掌握读代码的方法和填空的套路,就能拿到大部分分数。

一、看懂设计模式代码的"三步法"

第 1 步:找接口/抽象类 —— 看哪个是 abstract class 或 interface,那是模式的"契约"。
第 2 步:找具体实现类 —— 看哪些类 extends/implements 了上面的接口,那是"具体实现"。
第 3 步:找核心角色 —— 每个模式都有一个干主要事情的类,找到它就懂了整个模式。

二、看懂 C 算法代码的"四看法"

  1. 看函数名:Heapify = 调堆,MergeSort = 归并排序,函数名直接告诉你它在干嘛。
  2. 看参数:参数列表告诉你这个函数"需要什么输入"。
  3. 看注释:真题代码里中文注释就是答案的翻译!
  4. 看循环:单层 for 是 O(n),双层嵌套是 O(n²),while + /2 是 O(log n)。

⚙️ 经典算法(6 个)逐行讲解

📦 1. 0-1 背包问题(动态规划)

一句话:N 个物品,每个有重量和价值,背包容量 W,每件物品要么选要么不选,求最大价值。

核心状态转移方程:f[i][j] = max(f[i-1][j], f[i-1][j-w[i]] + v[i])
意思:第 i 件物品在容量 j 时的最大价值 = max(不选它, 选它)
// f[i][j] 表示前 i 件物品在容量 j 时的最大价值
for (i = 1; i <= N; i++) {           // 遍历每件物品
    for (j = 1; j <= W; j++) {        // 遍历每个容量
        f[i][j] = f[i-1][j];            // 默认不选第 i 件
        if (j >= w[i]) {              // 能装下第 i 件时
            // 选或不选取较大值
            f[i][j] = max(f[i][j], f[i-1][j-w[i]] + v[i]);
        }
    }
}
// 答案在 f[N][W]
填空套路:① 看到 f[i][j] = max(...) 就是状态转移;② 选物品的表达式永远是 f[i-1][j-w[i]] + v[i];③ 不选就是 f[i-1][j]。

📦 2. 部分背包问题(贪心算法)

一句话:和 0-1 背包的区别是物品可以切一部分,按"单位重量价值"从大到小排序,能装就全装,装不下就装一部分。

贪心策略:按 v[i]/w[i](单位价值)从大到小排序,依次取。
// 先按单位价值从大到小排序(用归并排序)
for (i = 1; i <= N; i++) {
    if (W_temp >= w[i]) {         // 背包还能装下整件
        answer[i] = 1.0;              // 全装
        result += v[i];
        W_temp -= w[i];
    } else {                       // 装不下了
        break;
    }
}
if (W_temp > 0 && i <= N) {       // 还有剩余容量和物品
    answer[i] = (double)W_temp / w[i]; // 装一部分
    result += W_temp * vw[i];         // 按单位价值算
}
0-1 背包 vs 部分背包:0-1 背包用动态规划(不能切),部分背包用贪心(能切)。别搞混!

📦 3. 归并排序(分治法)

一句话:把数组对半分,分别排好再合并。分治三步:分→治→合。

void MergeSort(int A[], int p, int r) {
    int q;
    if (p < r) {                    // 至少 2 个元素才分
        q = (p + r) / 2;             // 找中点
        MergeSort(A, p, q);         // 排左半
        MergeSort(A, q+1, r);       // 排右半
        Merge(A, p, q, r);           // 合并两半
    }
}
// Merge:用两个临时数组 L[]、R[] 分别存左右半,设哨兵 INT_MAX
// 然后双指针比较,小的放回 A[]
填空套路:① 递归终止条件 p < r;② 中点 q = (p+r)/2;③ 两次递归调用 MergeSort(A,p,q) 和 MergeSort(A,q+1,r);④ 合并 Merge(A,p,q,r)。

📦 4. 最大子段和(分治法)

一句话:数组中连续一段的最大和。分治:最大子段和要么在左半,要么在右半,要么横跨中间。

int MaxSubSum(int *Array, int left, int right) {
    if (left == right) {            // 只有一个元素
        return Array[left] > 0 ? Array[left] : 0;
    }
    int center = (left + right) / 2;
    int leftSum = MaxSubSum(Array, left, center);     // 左半最大
    int rightSum = MaxSubSum(Array, center+1, right); // 右半最大
    // 横跨中间:从 center 往左扫,从 center+1 往右扫
    int s1=0, lefts=0;
    for (i = center; i >= left; i--) {
        lefts += Array[i];
        if (lefts > s1) s1 = lefts;     // 左半最大后缀和
    }
    int s2=0, rights=0;
    for (i = center+1; i <= right; i++) {
        rights += Array[i];
        if (rights > s2) s2 = rights;   // 右半最大前缀和
    }
    int sum = s1 + s2;                // 横跨中间的最大和
    return max(sum, max(leftSum, rightSum)); // 三者取最大
}
填空套路:① 递归终止 left == right;② 中点 (left+right)/2;③ 横跨和 = 左半最大后缀 + 右半最大前缀;④ 最终返回三者最大值。

📦 5. N 皇后问题(回溯法)

一句话:N×N 棋盘放 N 个皇后,任意两个不能同行同列同斜线。回溯:逐行放,放不下就回退。

int q[N+1];   // q[j] = i 表示第 j 行的皇后在第 i 列

int check(int j) {  // 检查第 j 行的皇后位置是否合法
    for (int i = 1; i < j; i++) {
        // 同列 或 同斜线(行差 == 列差)
        if (q[i] == q[j] || abs(i - j) == abs(q[i] - q[j]))
            return 0;
    }
    return 1;
}

void queen(int j) {  // 摆放第 j 行的皇后
    for (int i = 1; i <= N; i++) {  // 试每一列
        q[j] = i;
        if (check(j)) {             // 位置合法
            if (j == N) {           // 最后一行也放好了,找到一组解
                printf("方案:%d", ...);
            } else {
                queen(j + 1);     // 递归摆下一行
            }
        }
        // 不合法就继续试下一列(自动回溯)
    }
}
填空套路:① check 里判断 q[i]==q[j] || abs(i-j)==abs(q[i]-q[j]);② 递归调用 queen(j+1);③ 终止条件 j==N。

🎲 蒙分三招(实在不会时用)

第 1 招:找上下文变量

题目代码里定义了 int i, j, max;,但下文 max 没用过 → 填空处大概率是 max = ...。

代码里定义了但没用的变量、返回类型、参数,往往就是填空答案的线索。

第 2 招:死记三大模板

算法必填代码
二分查找while (low <= high) 和 mid = (low + high) / 2
冒泡排序外层 for(i=0; i<n-1; i++),内层 j < n-1-i
